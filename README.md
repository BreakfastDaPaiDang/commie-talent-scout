# 康米巨星猎头系统

早餐社内部的人物与组织协作档案。把分散在聊天中的信息、接触进度和材料放到同一处，让成员知道：对象是谁、谁在跟进、最近发生了什么、下一步需要做什么。

**[进入正式站](https://scout.dapaidang.org) · [成员上手指南](./docs/member-guide.md) · [可转发的项目介绍](./docs/introduction.md)**

当前正式版本 **v0.1.1**，已上线。账号由管理员开通，无自助注册；首次登录按提示设置自己的密码。电脑和手机均可使用。

## 可以做什么

- **共同维护档案**：人物、组织分开管理，记录联系方式、来源链接、当前状态和负责成员，先搜索再新建，减少重复接触。
- **留下观察与进展**：发布文字和图片，保存草稿，查看修改历史和未读更新。
- **整理标签与材料**：用有依据的标签检索对象；在档案内上传、预览和下载绑定材料。
- **提醒持续跟进**：开启档案超过 30 天未更新，卡片置顶提示“需更新或关闭”；人物的引荐中、人事审核、已加入待对接三个状态为 7 天。
- **结束与继续**：完成对接或不再跟进时关闭档案，保留记录；需要继续维护时重新开启。
- **让 Agent 协助**：从“Agent 接入”复制专用接入信息，让支持 MCP 的客户端查档案、整理材料、拟写观察和建议标签，在你的权限与授权范围内执行。

## 代码与内部资料

本仓库公开维护源码和项目文档。正式站的普通档案供登录成员共同查看，不是个人私有笔记；删除内容按作者、上传者和管理员权限限制读取。

真实档案、观察、上传文件、账号、备份及凭证不进入公开仓库。报告问题时请说明操作步骤和现象，勿在公开 Issue 中粘贴内部材料、密码或 Agent 接入信息。

根目录是正式应用，`app/ui/` 是正式站与原型共用的界面。`prototypes/frontend/` 仅含虚构演示数据，刷新复位；`spikes/` 保留历史技术验证，均不参与正式构建。本地运行步骤见[开发说明](./docs/development.md)。
