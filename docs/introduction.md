# 给组织成员的项目介绍

以下内容可直接转发。

---

我们上线了「康米巨星猎头系统」，作为组织内部共同维护的人物和组织档案。

以后遇到值得关注或正在接触的对象，可以把资料、聊天中的重要进展和相关文件留在这里。其他成员能接着看、接着跟进，少一些信息散落和重复接触。

入口：**https://scout.dapaidang.org**，电脑和手机都能用。账号由管理员开通，第一次登录按提示设置自己的密码。

平时主要做几件事：

- 先搜索有没有现成档案，再补资料或新建。
- 有新情况就写一条观察，几句话把事实、进展和必要判断讲清楚，也能附图片。
- 更新接触状态和负责成员，用标签帮助检索，把文件放进“绑定材料”。
- 看“未读更新”接上别人的进展；看到“需更新或关闭”时，核实近况后更新，或结束跟进并关闭档案。

开启档案超过 30 天没有更新会置顶提醒；人物的引荐中、人事审核、已加入待对接三个状态是 7 天。

有在用支持 MCP 的 AI Agent，也可以从“Agent 接入”复制接入信息给自己的 Agent，让它帮忙查档案、整理材料和拟写记录。这是可选用法，日常操作直接在网页完成即可。

第一次可以从**搜一个自己了解的对象、补一条真实进展**开始。不会用或发现问题，直接反馈给管理员。

使用说明：[成员上手指南](https://github.com/BreakfastDaPaiDang/commie-talent-scout/blob/main/docs/member-guide.md)。
