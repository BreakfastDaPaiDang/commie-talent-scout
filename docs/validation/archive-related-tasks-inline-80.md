# 档案主页面关联任务与快捷操作 · #80

日期：2026-10-12。状态：本地验收通过，用户已确认并授权发布主站；生产发布结果与 CI 记录在 #80 跟踪。

## 本轮设计

取代 #79 的独立关联任务页签：外部人物、社员、组织的主页面常显关联任务，默认读取所有开启任务；通过单一文字入口切换关闭历史。紧凑行显示标题、负责人、状态，复用原任务行和详情弹窗，保留分页、加载失败重试及迟到响应隔离。

外部人物在当前状态适用时显示一个快捷操作，复用任务操作区样式；社员、组织、关闭或删除档案不显示。状态确认调用完整编辑的 `/archives/state`，保留目标状态已有成员绑定、版本检查和稳定请求 ID；状态推进不完成原有任务，转为已入伙后同 ID 进入社员页面。

没有新增表、迁移或另一套流程规则；原型和正式页面继续引用共享界面组件。PRD 修订 5、前端约定已同步。
