## 复现与证据

启动原型 `npm run dev --prefix prototypes/frontend`，运行 `node scripts/verify-flow-prototype.mjs`。可用 `CTS_FLOW_BASE` 指向其他本地预览地址，`CTS_TEST_BROWSER=chrome` 更换浏览器。临时截图及报告写入 `tmp/verification/flow-prototype/`；选定截图保存于 [设计目录](../design/1.0.0-flow/README.md)。现有真实接口回归需另行启动 `npm run dev:worker` 并准备本地开发账号。

本轮没有部署、生产迁移或远端 Issue 状态修改。新原型的网络错误、服务端并发、真实权限和持久化待正式接口实施后验收；内存断言不能代替这些验证。
