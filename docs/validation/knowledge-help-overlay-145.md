# 原页面按钮说明（#145，2026-11-14）

用户批准 [按钮说明示意图](../design/assets/knowledge-help-overlay-approved.png)，要求直接映射在原页面并上线。

共享 `KnowledgeHelp` 改为取页面上实际可见控件的边界，绘制文字标注、红色引线和端点。正常状态只保留问号入口；不加载教学截图、不弹出搜索教程、不增加常驻侧栏。简／繁与演示原型使用同一组件。

三个范围使用已确认的内容定义：

- 主要：已形成共识，当前采用的正式内容。
- 公开：已经提交，供成员讨论和审核的候选内容。
- 草稿：尚未提交，仅自己可见的个人内容。

打开说明时，左侧标题和范围下方临时留出标注空隙。标签依据真实位置计算，避免相互重叠；滚动、视口调整、字体加载及界面变化会重新定位，只读接收者不会看到写入操作说明。点击空白处、再次点击问号或按 Esc 退出，关闭按钮也支持键盘；退出点击不穿透到原页面。关闭恢复原布局、滚动位置和触发按钮焦点。

验收脚本 `scripts/verify-knowledge-help.mjs` 由真实双数据库 HTTP 验收调用；覆盖：

- 桌面 1440px、缩到 1024px、手机 390px／320px，说明框不重叠、不越界，红点仍落在真实控件上。
- 三条范围定义、正文批注、分享、修改、评论和繁模式议题／分支／历史入口。
- 页面滚动后重新定位；打开／关闭无知识库写请求，点击原“新条目”仅退出说明。
- 焦点进入／恢复、Tab、Esc、点击空白退出、关闭后原布局与阅读位置恢复。
- 夜间、空草稿、只读接收者、普通演示原型。
- 分类侧栏打开时启动说明，保持侧栏与当前阅读状态，原位解释编辑、关闭和留言控件；退出说明后侧栏仍保留。
- 原有完整编辑与提交页、评论批注、分类、三人同意、多候选与分支删除流程继续通过真实接口验收。
