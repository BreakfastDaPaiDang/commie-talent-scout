# v0.1.0 S5 验收

2026-09-08，对应 Issue #6。文字观察、可追溯编辑、原作者权限、版本历史、实体历史线、仅观察视图、草稿与阅读位置恢复已部署隔离测试环境。

本地与 Cloudflare 各通过 4 组观察行为、3 组草稿行为及 3 组边界检查：网页/MCP 原请求重试只发布一条记录；发生时间与提交时间分开；无变化不生成版本；并发编辑只提交一次；普通成员不能改他人记录，管理员编辑和冻结账号均不改变原作者。发布与关闭并发只允许一项提交，关闭后所有成员均不能新增或编辑观察。当前记录、旧版本及历史分页有效，同一记录只在最近动态位置展开为内容卡片。

正文保留段落，最多 100,000 个字符；旧版本不可覆盖，内容版本与用于写入冲突检查的记录版本分开。系统事件只保存记录/版本引用，不复制正文，为删除后的读取权限提供统一边界。删除、图片与标签工具仍由后续切片交付。

草稿存在 D1，只有本人能读取，按成员和档案独立保存；最近保存后保留 30 天，读取和定时清理均执行期限。保存失败保留本页输入并提示，离页触发保存，刷新前仍有未保存输入时浏览器提示；退出先完成待保存草稿，成功后清理浏览器内存。已保存草稿在刷新或退出后仍可继续，正文不写入 localStorage。草稿保存不改活动时间或生成动态，同一草稿并发保存明确冲突。草稿自己的发布请求标识跨刷新保留；已提交出版能从收据识别，重试不重复发布，成功后才清除对应草稿。到期草稿能重新保存，不因旧行残留陷入版本冲突。

浏览器实际保存并刷新恢复 1,430 字虚构草稿，跨人物/组织切页不丢失；发布后观察数为 1、草稿标记清除。修订后版本 2 为 1,454 字，版本 1 仍为原始 1,430 字。桌面正文 21 px/行高 38.85 px；手机正文 19 px/行高 35.15 px，实际 390 px 页面内正文左右 24/347，旧版本弹窗左右 21/369。仅观察视图不含系统事件。离开长文时滚动位置 1,164 px，重新打开同一档案恢复为 1,164 px；阅读位置按成员/档案保存于本机当前浏览器会话，恢复已加载分页及视图。截图接口限制延续 S2，未声称完成截图视觉审查。
