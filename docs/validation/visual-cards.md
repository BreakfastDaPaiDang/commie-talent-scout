# 档案卡片视觉验收 · Issue #17

## 最终行为

- 去掉档案数与排序整行；范围总数保留，清除条件移到展开的筛选区。
- 成员直接显示头像和姓名，无成员时没有占位说明。
- 标签只显示名称，同类别同颜色，不再显示类别前缀和重点星号；点击仍可看定义与依据。
- 左侧头像与辅助文字缩小，压缩卡片间距。已弃用的大叉、已入伙的大勾直接盖在淡化的卡片内容上，表达已结束、不必细看。点击仍可进入只读详情并重新开启。
- 图片提示仅“可粘贴”；普通保存成功提示自动消失。
