# 从确认原型直接接入正式接口

对应 Issue #15。上次以局部结构和 CSS 覆盖修复后仍偏离原型，用户于 2026-09-09 要求纠正实现方法。本轮重新打开 Issue，按 `531ab51` 的原型源代码完成迁移。

`app/ui/` 成为原型和正式站共同使用的界面来源：顶部导航、档案列表、范围与筛选行、详情固定工具栏与独立滚动区、展开阅读、资料区、时间线页签、输入框、记录段落与作者栏、未读条目、成员搜索下拉及弹窗。正式站的接口、权限、版本、幂等、持久草稿、上传和阅读回执仍由现有业务适配器处理。基础三份 CSS 与历史提交逐字一致，旧正式页面布局和 assembly.css 已移除。标签与连续操作分组作为正式功能扩展保留。

验证采用独立无界面 Edge，使用干净临时上下文，不依赖原浏览器扩展或用户窗口。

- 重现：原测试新增筛选同行、独立滚动区和展开阅读入口要求，在旧正式页面失败；迁移后通过。
- 历史对照：自动从 Git 取出 `531ab51`，同时运行历史原型、当前原型和正式构建。在 1920、1440、1024、390 四种宽度比较所选布局、字号、段落、输入框、时间线指标，差异为零，没有页面横向溢出。对照截图已逐一抽查桌面和手机。标签区域、真实计数/时间、权限控制和后加业务内容不冒充像素完全相同。
- 交互：展开/收起阅读、动态页签方向键和 Home、`/` 聚焦搜索、弹窗初始焦点/Escape 返回、未读队列定位和自动确认通过。
- 正式接口：本地和云端 staging 的真实数据库/HTTP/MCP 各四组通过：编辑和历史版本；草稿、PNG 上传、发布恰好一条、图片成功解码显示、清理草稿内容；真实成员目录与工作状态绑定；筛选和头像管理入口。测试档案最终关闭，额外登录和测试凭证清理。云端结果见[脱敏记录](./design-parity/workspace-ui-cloud.json)。
- 修复测试发现的问题：成员下拉的 Escape 原本仅 stopPropagation，仍触发原生 dialog cancel；共用组件增加 preventDefault，确保只关闭下拉。状态下拉补充明确的可访问名称。发布后草稿保留空版本行属于既有语义，验证改为确认正文/附件已清空。
