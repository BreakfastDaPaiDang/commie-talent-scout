# 档案资源与分层人员流向验收（#106）

本轮按用户最新确认，依赖现有档案、人事状态、任务、观察、材料及关联成员，增加一个结构化资源字段。没有初始化示例容器或另建人员资料；示例仅存在于原型及独立验收数据中。

## 实际行为

- 人物、社员、组织的原资料表单可新增、移除和展开资源条目，填写名称、类型、说明，选择可用／计划／实际使用，并通过分页搜索关联已有档案。档案详情显示条目及关联入口。
- `/personnel` 从账号菜单“人员流向与资源”或联动规则页进入。阶段沿用既有状态，外部社友与组织资源分别展示。每层展示去重人数、需跟进人数、资源及来源档案的材料和观察数量。
- 已关联档案的条目使用该档案的真实名称聚合容器；未关联条目按来源档案及条目 ID 区分，同名或复制 ID 都不自动合并。未登记实际归属的人员显示为“归属待补充”。
- 实际关联与计划关联单独计数；共同关联人员、明确登记的实际资源关联、真实阶段变更使用不同连线语义。阶段变更使用当时的资源快照，当前归属不会反向改写过去。
- 容器和连线详情可以查人员、当前需求、阶段停留、未领取/超期任务、资源说明和来源资料；资源编辑复用原 `ArchiveForm`。手机默认容器列表，可切换画布、缩放及查看详情。
- 搜索档案或资源名称会保留相关人员；隐藏目标不能通过搜索、详情、列表、历史、时间线或图形化接口泄漏。

## 本轮边界

资源数据保存为既有档案上的条目，不引入独立工作流、容量账本或审批。没有登记承接容量与建设目标时，不推算剩余名额或资源不足；“需跟进”来自现有超期提醒、超期任务和待承接任务。业务状态仍通过现有状态/交付操作修改。

当前图读取最多 1000 份匹配的开启档案，时间范围内最多 2000 条阶段变更；超过限制会明确提示不完整并要求缩小查询。阶段人数是当前分布，变更时间范围不截断当前人数，也不将其包装为累计转化率。

验证仅在本地执行，本轮尚未合并或部署生产。
