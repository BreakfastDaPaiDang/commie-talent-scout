# v0.1.0 S12 / S14 标签公共维护验收

2026-09-09，对应 Issue #11、#13。网页、共享 HTTP/MCP 服务及迁移 0011 已实现并在隔离 staging 验证。真实 Codex 新会话的词库写入验收尚未运行，两个 Issue 保持开启；本报告不把 SDK 测试客户端称为真实 Codex。

标签筛选按当前类别同类“或”、跨类“且”，与关键词、当前负责人、状态及开启/关闭组合。SQL 在分页与计数前应用来源权限，关闭档案匹配冻结绑定的稳定 ID；标签最多 30 个，分组使用单个 JSON 参数。词库检索包含类别、名称与描述，单次查询返回可见绑定计数。词条详情按开启/关闭分页展示档案与依据，定义历史保留旧措辞。

更名、澄清、换类、停用及迁移共用成员身份约束的预览。定义、绑定集合、来源可见性或关闭状态变化会使旧预览失效，提交事务再次复核；影响修订仅服务端可见。澄清和类别颜色维护不修改档案活动或未读；关闭快照保留当时词义，颜色采用当前显示设置。

含义改变使用新词条并逐档案提供支持新含义的依据，只迁移明确选中的开启档案。管理员同义合并去重来源，目标已有重点时保留目标位置；保留原添加者与历史，源词条停用并提供跳转。每批最多 10 个档案，整批原子提交；结果列出完成档案、剩余开启绑定和关闭保留项，后续批次重新预览。恢复已合并词条不会自动迁回已完成的绑定，旧合并历史保留。
