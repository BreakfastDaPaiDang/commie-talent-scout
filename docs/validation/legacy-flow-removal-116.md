# 旧图谱撤下

用户要求撤下 #103、#107、#109、#111、#113 引入的图谱与资源系统，正式功能以 a156c8f 为基线。

移除人员图谱、社内资源目录、资源调动和系统联动图的页面、导航、共享组件、HTTP/MCP 工具、相关生成物及档案资源输入契约。任务交付中的直接留档、观察引用、明确结论推进、账号绑定等先前功能保留。后续 #115 的 HTTPS 接入修复继续保留。

0036、0037 是已发布且兼容的数据库迁移，保留文件及原校验值；不回退数据、不清空资源历史。旧资源不再通过应用接口暴露，新开发不得复用这些旧接口或以旧图谱作为代码基线。

验证：类型检查、规则生成一致性、37 项迁移清单通过；服务测试中的旧功能回归通过，新增测试核对六个已撤下 HTTP 路由返回 404、MCP 不再公开旧工具或资源字段契约。DOM、构建、历史原型及发布结果以本次 CI 和发布记录为准。
