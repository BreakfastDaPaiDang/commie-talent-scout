# MCP Agent 可用性与任务默认排序验收 · #89 / #90

2026-10-12。此记录核对已实施功能，不宣称完成 #65、#66 的最终版本验收。

## 变更与使用路径

- `whoami.guide_topics` 与 `get_usage_guide` 的入参来自同一主题定义，修复 work_tasks 被推荐但不能调用的问题。补齐档案、社员、任务、统一消息和当前月度规则指南。
- `get_work_task` 保留任务、评论、事件，返回各自续页游标；新增 `list_work_task_history` 与 HTTP `/work-tasks/:id/history`，每部分最近记录优先，可继续读完。评论、引用及档案权限在每次续页重新校验；详情按需显示“加载更早记录”。
- 图片与材料共 16 个工具补齐 outputSchema；旧消息工具保持兼容，明确首批 100 条的限制，推荐可分页的统一 notifications 接口。
- 验收脚本使用早纪的 verification 身份；保留协议、权限隔离、日志脱敏、连接撤销验证。没有给业务调度增加管理员登录依赖。
- 任务簿、推荐、看板和 API 默认 P0 → P1 → P2，同级最近更新。看板仍可改为最近更新或截止时间，重置恢复默认。
