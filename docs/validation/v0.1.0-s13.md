# v0.1.0 S13 管理员任务审阅验收

2026-09-09，对应 Issue #12。迁移 0012、任务/调用/统计接口和管理员页面已在隔离 staging 实现并验收；云端完整联验版本 `3b7032dd-a1c9-4ce7-91e3-05b25896f5a3`，最终页面修订部署 `741ee506-bc8e-4c2d-aba3-b76c51ddeb11`。本报告的 MCP 客户端为 SDK 验收程序，不宣称新一轮真实 Codex 冷启动。

管理员从现有 Agent 调用入口查看任务、调用和统计。任务详情区分用户原话、Agent 转述、来源副本和服务实际产物；缺少原话或模型时显示未知，显式提供的模型仅标为 Agent 自报。无明确任务 ID 的调用单列，不按成员、凭证或相近时间归组。调用尝试 ID、业务请求 ID 与任务 ID 分开展示。

结果留存只保留服务适配器提交的有界摘要；长期投影只允许产物 ID、版本、变更/重放标志及批次完成范围。任务产物可跳转到当前档案或观察，并显示提交版本和后续版本变化，不据此推断质量。新建观察、标签新建/复用和绑定变更排除已知重放；调用次数仍按真实尝试计数。

任务目的、原话、转述、源材料和自报模型保留 30 天，读取时先判到期；调用元信息保留 180 天。清理先把过期记录折叠为不含成员、凭证、任务或产物标识的 UTC 日汇总，再删除元信息，整批事务可回滚和重试。来源缺失时隐藏可能混合引用的副本与任务目的；已删除观察仍按现行管理员读取权限处理。普通成员、匿名和降权后的旧会话不能读取管理分析接口。正文及结构字段中的可识别秘密均经过过滤。

验收见 [JSON](./v0.1.0-s13.json)：

- 4 项真实 SQLite 服务测试覆盖任务和尝试关联、业务收据重放、产物后续编辑/删除、原话未知、模型自报、来源删除和缺失、脱敏、有界材料、标签计数、批次范围，以及 31/181 天清理和注入失败后的完整回滚。清理后正常观察和版本仍可读取，第二次清理不重复累计。
- `verify-task-review.mjs` 本地、云端各 4 组通过。实际 SDK 创建虚构任务并重放，通过真实 HTTP 与 Edge 页面核对产物、原话、来源、请求摘要、统计和未关联调用；验证普通成员拒绝、提升并重新登录可读、降权后旧会话立即失效。
- 完整任务弹窗和统计首屏在 390px 下无横向溢出，截图已人工查看；筛选条件折叠，任务与统计优先展示，来源和采集说明按需展开。
- 历史原型 `531ab51` 的四宽度对照通过；25 项界面简化、5 项 DOM 和实际工作区 6 组回归通过，沿用原型的弹窗与基础组件。最后补充洛杉矶浏览器下的北京时间显示/筛选及匿名接口拒绝，本地实际页面复测通过。

统计说明保留在管理页面折叠区域：调用按所选时间、操作、结果计数，新任务数按任务创建时间单独计数；过期记录只有 UTC 整日汇总，不能恢复精确时段或身份。采集失败和历史缺失字段可能少计，关联率只表示已采集调用的明确关联比例，不代表所有外部 Agent 行为。生产上线按 Issue #14 继续。
