# 0.1.1 绑定材料验收

2026-09-09，关联 #30、#31。

材料入口、文件列表、编辑与额度表单以及 PDF 预览由原型与正式站共用。网页和 MCP 已实现上传、状态查询、取消、列表、下载、稳定引用、名称/说明维护、回收站、恢复、彻底删除及单档案额度管理。人物默认 100MB，组织默认 200MB，单文件最大 100MB，均为十进制单位。

- 全量服务测试 54 项通过；随后新增慢上传在清理后完成的回归，材料专项共 7 项通过（全量现为 55 项）。真实 SQLite 事务覆盖并发容量、版本、角色、档案状态、撤销凭据、回收计量和删除失败恢复。
- 原有 DOM 6 项通过，新增材料范围切换延迟响应测试通过（现为 7 项）。切换范围先移除旧条目，迟到请求不能提供旧版本操作。
- 类型检查、构建和迁移清单检查通过。历史 `531ab51` 原型与当前原型、正式构建对照通过四个宽度；仅将已确认的手机第四页签 12px 间距作为明确差异。编辑、发布、卡片与标签等既有界面检查通过。
- `verify-materials.mjs` 本地 6 项通过；云端实际完成 100,000,000 字节上传与下载，SHA-256 一致、匿名下载被拒绝。修复回收站快速切换后，云端完整流程 6 项通过，涵盖桌面上传及编辑、未提交观察保留、手机删除与恢复、管理员扩容、图片/PDF 实际预览和稳定引用定位。
- `verify-workspace-ui.mjs --remote` 6 项通过，验证已有档案资料、标签、图文观察、历史、草稿和未读的真实接口路径。
- `verify-material-recovery.mjs --remote --backup` 4 项通过：转发真实上传后丢弃响应，重试不重复传输/创建；MCP Bearer 下载与撤销；多文件拖入及手机彻底删除；私有云端快照包含回收站材料并核对内容哈希。该快照新增两个内容块，共 98 字节，验收文件随后清除、档案关闭、临时凭据撤销。

## 修复与发布边界

浏览器原生内嵌 PDF 受到限制，改为按需加载本地 PDF.js，实际页面已渲染并检查截图。文件菜单执行操作后收起。材料范围和上传异步回调使用当前范围与请求序号，避免旧列表/版本跨范围出现；完成上传后释放浏览器队列中的文件引用。

备份从快照数据库枚举材料，包括回收站，沿用原有内容寻址对象格式；恢复按单文件处理，避免将全部材料累积于内存。已发布的旧迁移与 v0.1.0 tag 保持不变，0015 仅增加新表和默认字段。发布冒烟按产品版本核对，代码回退时使用先前版本进行核对。

正式部署使用既有自动流程：检查、私有备份、兼容迁移、部署及冒烟。没有重复执行多轮真实 Agent 对话；MCP 原始文件取用不包含自动全文解析，也不把上传成功表述为 Agent 已阅读。
