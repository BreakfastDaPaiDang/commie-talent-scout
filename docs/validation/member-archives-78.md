# 社员档案重构验收（#78）

日期：2026-10-12。需求基线为 PRD 1.0.0 修订 3 §4.5。本记录使用虚构档案和本地真实 Worker，不代表整个 1.0.0 已验收，也不代表历史生产数据已修正。

## 实现结果

- 同一人物档案增加 `person_role`、`member_status`，保留 ID、资料、观察、材料与任务引用。已加入待对接属于外部人物，已入伙转入社员；基本状态独立维护为可接工作、请假、失联。
- 审核、确认加入的快捷入口与普通状态编辑共用档案事务，自动任务、发起人和历史一起提交。未完成任务不阻塞转档，转档不完成任务；审核／对接交付提示从当前档案读取派生。
- 社员完整编辑沿用共享档案组件；状态选项和筛选采用基本状态，取消完成勾及“更新或关闭”提醒。显式转为外部社友保持开启；退出组织才转外部并关闭。
- 三种基本状态都继续生成月度跟进；无变化保存不增版本，重复命令不重复留史，资料或任务失败整体回滚。网页与 MCP 使用相同校验、权限及查询。
- 已移动档案的旧链接定位新页面；仅从页面偏好恢复的旧选择会清掉，避免用户主动进入外部人物页面却又被跳回社员。

## 兼容边界

迁移 `0028` 只加可空字段与索引，不批量 UPDATE 旧档案。旧 `person_role` 为空时通过旧已入伙状态识别身份，基本状态读取默认可接工作，不写回、不伪造入社日期或历史。旧关闭社员仍保持关闭，允许明确重新开启；社员列表不因隐藏的关闭时间偏好漏掉这些旧档案。

主用户系统同步、工作中派生状态和真实旧数据纠正均未实施。需要修正哪些旧档案，由用户另行指定范围。
