# 档案关联任务验收（#79）

日期：2026-10-12。需求基线：PRD 1.0.0 修订 4。此项只验收档案关联任务入口，不代表整个 1.0.0 完整验收。

## 实现

- 外部人物、社员、组织统一移除“下一步工作”及推进人事状态快捷按钮，新增“关联任务”页签。完整档案编辑仍可切换状态，并通过原有共享业务规则生成审核、对接任务。
- 页签数量为全部开启任务数，默认不限负责人、不排除逾期；已完成、取消等任务在“已关闭”中查看。列表每页 50 条，可继续读取，不依赖旧详情最多 30 条摘要。
- 复用任务簿列表行、状态图标、优先级及头像，看板大厅与档案使用同一任务详情弹窗。领取、编辑、交付、取消、重开后刷新列表和数量；完成后保留当前详情供用户查看结果。
- 切换任务／材料／观察保留未提交草稿，任务结果可以定位对应观察版本。档案内打开任务引用不会把返回目标改为任务簿。
- 旧详情的 `work_tasks` 保留兼容，新增 `open_task_count`；不改变业务规则、任务权限或迁移历史数据。
