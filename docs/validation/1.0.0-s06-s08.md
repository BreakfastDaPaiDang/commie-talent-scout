# 1.0.0 S06—S08 验收记录

本记录覆盖 #60、#61、#62 的当前实现。#62 已根据本地证据关闭，隔离云端综合验收仍由 S11 完成。

## 已覆盖行为

- #60：引荐、审核、明确入社共用同一人物档案；组织保留多个社员绑定；网页和 MCP 共用任务与观察接口。
- #61：管理员可预览和生成指定东八区自然月的任务；同一档案、任务类型和月份以唯一键去重；期限为该月上海时区最后一刻。任务支持领取、未联系到结果，以及创建或编辑关联观察后自动完成。
- #62：社员转为外部对象时取消月度和入社对接自动任务；关闭或删除档案时取消不适用的自动任务。合作任务保留，状态变化写入历史并通知负责人；重开不自动恢复取消的任务。

## 本地验证

`npm run check`、`npm test`、`npm run rules:check`、`node scripts/check-migrations.mjs`、`npm run build`、`npm run test:dom` 及 `git diff --check` 通过。

`tests/monthly-work-tasks.test.mjs` 覆盖人物与组织的月度生成、跨月去重、月末截止、观察创建和编辑联动、身份退出、关闭、重开、删除、合作保留及消息历史。

## 发布边界

月度任务有管理员 HTTP/MCP 预览和生成入口。定时生成需要有效管理员 MCP 凭据及 `MONTHLY_TASKS_ENABLED=true`；生产配置默认 `false`，staging 配置为 `true`。S12 核对真实映射、首批任务和起始月份后才开启生产定时生成。本次合入 main 不执行生产业务转换或正式首批任务生成。

真实 staging 的浏览器、MCP、Cron 与恢复演练仍由 S11 完成，不能以本地 SQLite 回归替代。
