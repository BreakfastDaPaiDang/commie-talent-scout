# v0.1.0 正式上线验收

2026-09-09，正式入口：https://scout.dapaidang.org 。应用版本为 `0.1.0`。

| 路径 | 正式环境证据 |
|---|---|
| 复制即接入 | 网页 4 组、默认 Python HTTP/上传 3 组、真实 Codex 无预置配置及独立冷启动 2 组；55 个工具和正确成员身份 |
| 标签公共维护 | 正式网页筛选/更名 4 组、合并/停用恢复 4 组、真实普通成员/管理员 Codex 4 组，含过期预览恢复及实际权限拒绝 |
| 图文与历史 | 真实 Codex 上传 PNG/JPEG、读取图像、发布，第二冷启动编辑为 JPEG/WebP 并读取旧 PNG，2 组；桌面/手机网页原图和历史联验 2 组 |
| 观察生命周期 | 真实 Codex 删除、恢复、关闭后拒绝写入，3 组；原作者及不可变内容版本保留 |
| 档案回收 | 真实 Codex 将已关闭档案移入回收再恢复，保留同一 ID、已弃用状态、原观察和作者，1 组 |
| 材料整理与审阅 | 真实 Codex 材料整理 1 组、正式网页联验 3 组；人工逐句核对说话者、时间范围、资源交接及技能边界 |
| 部署与恢复 | 46 项服务测试、5 项 DOM、四宽度历史对照和完整界面回归通过；自动部署完成备份与冒烟；新的隔离恢复核对 33 张表、5 张图片引用及恢复后清理 |
| 成员网络 | 维护者报告中国联通、无代理，目前使用未发现问题，有异常继续反馈；未声称覆盖其他运营商 |

实际客户端使用已有默认模型配置，未降低业务工具风险标记。确认请求按用户既有授权审查具体验收对象；只写专用虚构材料，连接撤销、测试成员冻结，验收档案关闭。观察和整张档案均经过真实模型客户端的可恢复删除与恢复。

材料整理保留九月周三 20:00–22:00（北京时间）及十月未知，不把频道权限交接当成视频技能丧失，也不把他人的 Python/英语能力或学习 Blender 的计划算到对象名下。原话和材料副本未由该客户端提交时，网页明确显示“未提供”，不把 Agent 转述当成用户原话；实际调用及产物仍可追溯。

本轮发现并修复：复制未携带认证、Cloudflare 浏览器特征检查误拦机器客户端、类别选项加载前空白、搜索测试同毫秒排序不稳定、备份本地校验未按 D1 导入事务延迟外键。失败与修复证据保留于对应报告。
