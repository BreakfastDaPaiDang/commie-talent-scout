# 社内承接资源与统计图谱整合验收（#108）

本次修正资源的领域含义：登记社内实际拥有、能接收或支持新人的资源。没有从外部组织、接触记录或用户举例初始化资源，也没有改写原有条目。

## 行为

- 社内资源清单独立于使用者，支持名称、类型、承接说明、适用阶段、开放/暂停/停用状态、可选同时承接名额和负责成员。未设置名额与零名额分别表达；重复安排按人物档案去重，计划不占实际人数；实际超额情况保留并明确显示。
- 原档案字段选择已登记社内资源，填写计划/已落实及落实说明。社内资源通过稳定 ID 统一名称与承接条件；编辑档案不会创建新的资源所有权或修改人员审核、入社身份。
- 旧的联系记录原样保留，仅可保留、移除或明确选择已登记资源；在流向图中作为“原有关联容器”背景单列，不计入社内资源资产。关联目标删除后的原有读取权限投影继续有效。
- 统计下辖 `/statistics/flow`，统一提供人员流向、社内承接资源、系统联动图三个视图。统计主导航持续高亮；旧 `/personnel`、`/rules` 转到对应子视图，浏览器前进后退同步。
- 资源表单、图内资源编辑、资源选择及统计导航均使用共享界面；共享原型也可切换上述视图及统计概览。原规则画布的布局保存、筛选、缩放、键盘与触摸操作继续保留。

## 验证

- 211 项服务测试、39 项 DOM 测试通过。资源专门行为包括无人使用的资源仍显示、外部联系不成为内部资产、未知/零名额、重复人数去重、计划/实际区分、旧字段省略与原样保留、冻结权限及退休资源与新安排并发时的事务回滚。
- 类型检查、规则视图检查、37 项兼容迁移清单及正式构建通过。
- 历史原型四宽度对照、完整展开资料/发布、卡片、头像及图片浏览回归通过。
- 真实工作区 6 组验收通过；迁入统计的规则画布 5 组验收通过；社内资源与统计整合 6 组真实 HTTP/MCP、桌面/手机验收通过，含手机负责成员弹层不遮挡、图内资源编辑、旧链接与前进后退。
- 验收仅在本地使用虚构记录，人员档案已删除、资源已停用、临时连接已撤销。没有写入生产业务数据。
