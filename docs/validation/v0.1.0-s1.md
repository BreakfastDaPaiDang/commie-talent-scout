# v0.1.0 S1 验收

2026-09-08，正式应用首条切片，对应 Issue #1。测试入口 https://scout-staging.dapaidang.org ，D1 `cts-staging`；尚未建立生产数据库。用户已确认账号现有 Workers Paid / R2 Paid，沿用订阅。

实际执行：`npm run check`、`npm test`（3 项）、`npm run build`；本地与云端 `verify-auth.mjs` 各 14 项、本地与云端 `verify-auth-boundaries.mjs` 各 4 项。覆盖真实账号密码、首次强制改密、旧会话失效、错误密码、跨来源写入拒绝、过期会话、退出重放、未认证业务/图片、无效 JSON、请求体上限和密码计算前限流。

初始化使用经 Cloudflare 管理认证的 D1 单条条件 INSERT，没有公开初始化接口。再次以不同用户名初始化本地数据库时插入被阻止；既有管理员保持不变。明文随机密码只落在 Git 忽略的私有目录，数据库只保存带随机盐及版本的 scrypt 派生值。验证用管理员的密码已在测试中轮换，生产初始化将生成独立的首次登录密码。

`verify-auth-load.mjs` 在真实 Worker 执行一次单请求及三路并发登录：全部 200，CPU 195–364 ms；客户端延迟 1068–2222 ms，包含网络和数据库等待。每个 isolate 仅允许一个昂贵 KDF 同时运行，单元行为验证确认超额计算被拒绝并可恢复；Worker 可分配不同 isolate，所以并发请求不必都收到 429。此小样本未观察到 CPU/内存耗尽，不是吞吐量保证。scrypt 工作内存约 32 MiB，分配上限 64 MiB；tail 未提供峰值堆内存，不能把分配上限当实测内存。CPU 配置上限 2000 ms，足够本轮验证。脱敏计时见相邻 JSON 文件。

浏览器检查 1920 px 桌面登录和空工作台、390 px 窄屏工作台。修复窄屏退出按钮被旧样式隐藏的问题，实际操作退出后检查登录表单和错误密码提示。部分浏览器截图调用超时，表单与反馈通过实时可访问性树确认。当前空工作台只提供后续档案页面的入口位置，档案能力由后续 Issue 交付。
