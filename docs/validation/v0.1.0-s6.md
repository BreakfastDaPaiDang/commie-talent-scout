# v0.1.0 S6 实现与验收

2026-09-09，对应 Issue #8。图像与头像的接口、浏览器和真实 Codex 联合验收已通过。正式站亦已部署，其浏览器与 SDK 检查见 [S10](./v0.1.0-s10.md)；以下真实 Codex 联验使用隔离测试站上的正式前端与真实数据服务。证据见 [JSON](./v0.1.0-s6.json)。

本地和 Cloudflare 各通过 7 组图像集成检查：票据绑定原凭证、成员 epoch、目的、档案/账号、真实类型、字节数与 SHA-256；不匹配、过期、重复完成均拒绝。上传失败可以用原固定内容重试，准备和上传不产生观察。PNG、JPEG、WebP 使用实际容器与尺寸检查，SVG/GIF/动画及超限内容拒绝；Worker 不运行完整像素解码器。原图保留质量，服务端单次上传固定缓冲区至多 10 MiB，并限制并发处理及读取期限。

图文或纯图片记录最多 10 图，图片顺序属于内容版本。省略编辑附件列表保留旧图，明确空列表移除当前图；历史引用不删除。草稿保留本人图片、发布请求和 30 天期限，纯图片草稿同样显示草稿标记。MCP `get_image` 返回标准 image 内容，普通读取仅返回元数据；图片、头像及原图地址每次鉴权，不返回公共长期链接。私有 R2 的 `r2.dev` 公开访问已实测为关闭。

本地与云端边界套件还通过真实 10 MiB PNG、十图发布、当前移除后历史十图保留、竞争上传仅一个成功、一个暂存图片不能同时归属两条观察、撤销原 MCP 凭证使票据失效。云端单次 10 MiB 上传耗时 8,350 ms，不作为性能分位数；标准 MCP image 响应完整取回 10 MiB 原图亦已独立通过。本地实际 scheduled 清理删除超期无引用上传，保留所有旧版本、当前草稿和已移除头像的历史对象，并成功读回其图片。一次复测因并行本地 workerd 重载触发 SQLite 锁而失去 scheduled 服务；重启本地测试服务后完整重测通过，未修改真实数据来恢复。

人物和猎头头像优先上传图，其次 QQ，最后默认形象；组织忽略 QQ。头像更换/移除按目标版本生成历史，账号资料与 QQ 单独维护，普通成员不能改他人账号。上传图有效时不会访问 QQ。真实 SQLite 服务测试用替代上游响应验证固定 QQ 地址、24 小时缓存、并发单次刷新、上游失败保留旧缓存、缓存刷新不改变业务活动时间；上传主体、关闭、冻结与私有读取另由本地/云端接口检查。当前单元及服务测试共 11 项通过。

页面已接入选图、粘贴、多图预览、进度、失败查询后重试、移除、历史图和原图缩放，并提供档案头像入口及“我的资料”。2026-09-09 已使用独立无界面 Edge 完成实际界面验收，不再受旧扩展调试连接影响。`verify-images-state-ui.mjs` 本地/云端各 5 组通过：三图选择的进度与单次 PUT 失败、发布禁用、状态查询后重试和一次发布；原图缩放、手机端移除当前图及粘贴事件输入、旧版本保留三图；纯图发布；JPEG 档案头像应用、版本冲突刷新和移除后回退。完整上传、编辑、恢复手机截图已查看。粘贴通过浏览器 ClipboardEvent 触发真实处理器，不称为系统剪贴板操作。部署 `741ee506-bc8e-4c2d-aba3-b76c51ddeb11`。

此前非交互客户端的文件读取被策略拒绝，该失败保留在 JSON 中。现通过真实 Codex app-server 将实际请求转交用户，获得限定文件、隔离站点及操作的明确批准后逐次执行；没有改低工具风险标记或关闭沙箱。

两轮独立冷启动通过：第一轮读取 PNG/JPEG 文件、校验真实类型和哈希、以 HTTP PUT 上传、查询就绪、通过 `get_image` 取回图片并准确描述红色方块和蓝色圆形，发布且读回一条双图记录；第二轮移除当前 PNG、保留 JPEG、上传并添加 WebP，再从不可变历史读回原 PNG。作者、记录及版本通过独立 HTTP/MCP 检查。最早图片会话在人工等待期间超时，尚未上传或发布；续验复用同一空档案，新建临时连接，未重复创建观察。

`verify-codex-images-web.mjs --remote` 随后在正式组件中读取同一条记录，实际解码当前 JPEG/WebP、手机历史 PNG/JPEG、打开旧版原图及原始尺寸视图；无页面溢出或运行错误。已查看[电脑端截图](./codex-images/desktop.png)、[手机历史](./codex-images/history-mobile.png)和[手机原图](./codex-images/original-mobile.png)。收尾关闭虚构档案、撤销测试连接并清除复制的认证文件。原始日志和令牌保持私有。

本地 MCP 曾因 Wrangler 默认上游域名生成错误上传地址，现显式设置本地 dev host；正式链接按实际请求域名生成。测试主机 IPv6 不稳定，验收进程显式使用 IPv4 并关闭自动切回 IPv6。Wrangler 的远程 SQL JSON 输出差异已修正。网络和验收脚本问题与产品业务断言分开记录。最后部署版本 `1f16011e-fd97-412f-819f-e9740253ecf7`。
