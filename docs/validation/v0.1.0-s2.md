# v0.1.0 S2 验收

2026-09-08，对应 Issue #2。正式应用在隔离测试环境交付 MCP 接入、个人连接管理、服务指南和管理员最小调用列表；档案/观察/标签功能仍由后续切片交付。

网页接入页共用短模板，填入当前真实地址与本人连接管理入口。复制成功有反馈；剪贴板失败时呈现可选择的正文。连接管理创建、命名及撤销个人凭证；明文仅保留在本次创建页面内，列表与数据库不保存明文。有效期默认 90 天，可选 1/30/90/365 天；最多 20 个有效连接。管理员可按时间和结果筛选调用并展开筛选后的参数与执行摘要，普通成员由服务端拒绝。

本地与真实 Cloudflare 协议验收各通过 6 组行为检查：未认证拒绝、秘密只显示一次、初始化与工具发现、指南、无效参数拒绝并区分调用尝试、普通成员权限、已连接客户端撤销即时失效。类型检查、构建及秘密筛选测试通过。新指南仅描述当前真实能力；核心路径不依赖 resources/prompts。

实际 scheduled Worker 清理验证：近期正文保留，31 天前正文/结果摘要清空，181 天前元数据删除，正常成员不受影响。查询也限制到期数据可见性。临时移开本地留存表后，已认证工具仍成功，另留无正文诊断；随后恢复表。未观察到完成状态的中断保留为“结果不明”，不假称业务失败。客户端名称/版本若未取得保持未知，不从共享凭证推断客户端身份。

真实 Codex CLI 0.153.0 使用短模板测试：临时模式通过命令级配置和仅该进程的认证变量接入，未写入 MCP 持久配置；持久模式使用隔离的私有客户端目录，两次独立进程均未注入临时 Bearer 变量，实际 `whoami` 成功并出现在服务记录中。配置文件和认证来源由验收脚本核对，配置内容在调用前后保持一致。未选择模式的会话明确询问是否需要持久配置，没有自行保存连接。三种测试均未向对话回显 MCP 秘密，测试凭证已撤销，复制的 ChatGPT 登录文件已清理。

证据边界：该隔离只读 CLI 的执行策略阻止模型检查本机文件，因此模型如实将自身未核验的配置项标为未核验；不能把脚本完成的文件核验描述成模型完成了首次配置安装。新进程真正执行了 MCP 身份调用，已排除仅配置存在或继承临时变量的伪验证。实现依据 [Codex 官方 MCP 配置](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)中的 Streamable HTTP、命令级配置与静态/环境认证支持，不宣称本站提供 OAuth。

浏览器完成复制反馈、创建连接、关闭秘密显示、撤销反馈、调用详情交互。核对页面实际 CSS 视口 390 px，表单与筛选控件均处于页面范围，没有横向溢出。S2 截图接口多次超时，不能据此声称完成了截图视觉审查；已审阅原型的资产与布局继续沿用，最终上线阶段复核整体页面。脱敏机器结果见 [相邻 JSON](./v0.1.0-s2.json)。
