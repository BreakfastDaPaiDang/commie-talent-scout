# 1.0.0 S05 消息提醒与任务期限验证

## 默认行为

- 负责人任务在当前截止时间前 24 小时进入提醒窗口；同一任务、负责人和截止时间只写入一条提醒。
- 调度器先执行严格过期，再生成提醒。调度器晚到不会补发已经过期的提醒，也不会给截止时间增加宽限。
- 无人领取的任务关闭原因为 `claim_deadline_missed`；已领取但未提交结果的任务关闭原因为 `completion_deadline_missed`。
- 延期、交还、领取、完成和关闭都会改变任务版本；消息只返回仍匹配当前任务版本和期限的提醒。
- 逾期未完成结果消息只发给原负责人；无人领取的失败留在任务看板，不广播给全体成员。

## 边界

消息读取与既有档案未读确认是两条独立路径。消息列表只返回当前成员可见的任务提醒和截止结果；档案被删除、成员被冻结或任务期限已被替换时，旧消息不会继续返回。当前实现不发送外部推送。
