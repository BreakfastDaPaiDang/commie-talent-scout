# 统计工作口径修复（Issue #110）

## 可演示结果

- `/statistics` 在观察记录量之外展示当前人员承接、本期登记推进与任务交付。当前人员标签按人物去重，独立于观察条数、观察分组和搜索。组织范围不展示人物统计；标签趋势明确按当前绑定回看，不能当作历史技能人数。
- `/statistics/flow?view=people` 增加人员工作清单、实际调动入口、近期登记变化和关闭／退出历史层。旧外部联系仍可查看，但不算已落实社内承接。可接工作社员的待安排、计划待落实分别提示；请假与暂不接工作不强制安排，失联提示联系。
- 阶段停留以建档、真实阶段变化或重新开启的时间为依据，推进阶段沿用 7／30 天核对期限；资料编辑不能清除停留提醒。稳定社友、社员不因停留时间长而被要求升级。
- 社内资源按人物去重计入已落实和净待落实；已在同资源落实的人不重复算待落实。当前空位、计划后余量、合计超额、暂停状态与负责情况分别展示。名额在所有阶段共享；未知名额保持未知。记录事实不被容量警告拦截。
- 网页与 MCP 的实际调动共用 `Archives.transferResource`，一次事务校验版本、写入资源安排、完整前后快照和请求收据。调出清理原资源已落实及重复计划，保留其他资源安排。响应丢失按原请求核对收据；退役目标并发变化、冻结凭据和写入失败均整体回滚。
- 普通资料编辑的资源增减列为独立变化，不推断配对路线；共同关联保持无向。历史按当时资源快照、当时阶段展示，关闭人员保留可见历史并从当前容量移除；删除档案继续隐藏。没有旧快照时标为未知，不倒推今天的安排。
- 统计筛选、对比分组、累计模式；图谱查询、时间、层级、容器／连线选择、显示模式；资源目录查询随链接与子页切换保留。前进后退恢复条件，复制链接携带当前已应用条件。

## 验证

- `tests/statistics-accuracy.test.mjs` 覆盖旧联系遮挡、资料更新后的阶段停留、稳定状态、同阶段调动、重复计划、幂等与回滚、退役竞态、关闭／删除历史、未知快照、建设指标和链接条件。
- `scripts/verify-statistics-accuracy.mjs` 在本机 staging Worker 使用本次虚构人物、资源、词库与真实 HTTP/MCP。覆盖标签人数与观察条数区别、未登录拒绝、复制链接跨页恢复、子页和前进后退、筛选图谱时查找全目录转入资源、1440／390px 完整调动表单、丢失响应后收据恢复、退出历史及容量释放。
- `verify-statistics.mjs`、`verify-personnel-resources.mjs`、`verify-workspace-ui.mjs`、`verify-interaction-graph.mjs` 回归现有统计、资源完整表单、手机负责成员选择、编辑发布、共享原型和联动图。
- `check-ui.mjs` 对照历史批准原型并覆盖完整编辑、发布区、手机布局及阅读功能；共享表单与图谱均仍位于 `app/ui/`。

截图和机器报告位于本机忽略目录 `tmp/verification/`。验收新建的人物随后可恢复删除，资源随后停用，虚构词库随后删除，临时连接撤销；没有修改线上业务记录。

## 口径边界

当前库存不等于所选日期末的历史库存；本期变化按登记时间统计，人物按指标去重，任务按交付事件次数统计，各指标不能直接相加或当作同批次转化率。历史快照只能复盘已经记录的事实，不能恢复从未采集的技能、安排和实际发生日期。

图谱保持当前最多 1000 份档案、最近 2000 条历史变化的显式截断提示；人员标签明细显示前 50 组并展示总组数。计划后余量用于协调承接压力，不代表自动预留名额或已完成接收。
