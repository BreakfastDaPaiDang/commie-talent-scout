# 注意力层级与标签弹窗验收 · Issue #18

## 修复与行为

标签完整显示“类别：名称”，同类别使用同一颜色、无星号区分。类别是领域语义的一部分，不能作为辅助字段名隐藏。

标签详情恢复正常标题栏和关闭按钮位置。通用定义为辅助文字，具体依据采用更显眼的正文，确认时间居后；查看来源与维护依据保留。

未读卡片显示红色“有更新”提示，最新时间用更醒目的颜色和字重；桌面时间 15px，手机 14px。已完成卡片的大勾叉仍直接覆盖淡化内容。未读提示放在淡化区域之外，已关闭档案有新变化时仍可识别。

正式资源恢复原型中已确认的望远镜空态插图。

## 故障证据

`node scripts/verify-attention-ui.mjs` 修改前复现 6 个失败项：类别缺失、未读提示缺失、时间偏小、桌面与手机标签标题栏失效、图片解码失败。

弹窗根因：`.archive-tags header` 使用 `display:contents`，命中了标签区内部弹窗的 `.modal-head`；h2 和其他后代选择器也影响内部对话框。改成标签区直接子元素，避免跨组件覆盖。修复后桌面／手机标题栏有正常内边距、标题与关闭按钮同排。

插图根因：图片在 `prototypes/frontend/public/art/`，正式构建使用根目录 `public/`，因此打包漏带；缺失路径返回 SPA HTML，HTTP 200 并不能证明图已加载。补齐正式资源，检查真实图片解码与响应字节。
