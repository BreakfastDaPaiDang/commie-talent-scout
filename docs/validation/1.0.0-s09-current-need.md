# 1.0.0 S09 / Issue #63 validation

This change keeps the approved archive editor and the existing archive/MCP commands. It adds a versioned, nullable-in-practice `current_need` value to every archive, plus a derived contact reminder.

## Behavior covered

- Person and organization archive create/update/get paths round-trip `current_need`.
- An update that omits `current_need` preserves the stored value; an explicit empty string clears it.
- The reminder applies only to joined people, external friends, and organizations in `个人接触` or `组织交流`.
- Contact entries are counted by normalized channel and account/address. Duplicate entries do not count twice.
- A successful write returns `contact_reminder` when fewer than two distinct usable contacts exist. The reminder never rejects a save and does not create a task.
- MCP archive guidance tells an Agent to read before updating, record explicit needs from authorized material, preserve omitted values, and treat contact reminders as follow-up hints.
