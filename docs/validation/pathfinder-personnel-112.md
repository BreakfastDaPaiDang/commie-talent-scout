# 人员等级与承接工作区重构（Issue #112）

用户要求删除上一版并重构。本版撤下 Pathfinder 桑基画布与全部几何布局，改为当前人员等级与承接容器的分栏工作区。红白黄配色、真实数据与共享界面保持。

## 数据口径

默认接口按待审核（观察／接触／引荐明细合并）、审核中、审核通过、社员、社外社友呈现。档案状态、审核结论与实际安排不改写；`group_by:status` 保留细分状态。观察转接触不当作等级变化。

同等级同资源只显示一个容器，等级人数和容器人数分别去重，跨容器不可相加。资源容量全等级共享，未知容量不推算；只在历史经过的资源保留详情和流动事实，不计入当前该等级资源数。组织独立以“家”统计，保持实际联系状态，打开组织档案，不套人员审核或承接名额。

## 共享界面

原型与正式页继续使用 `app/ui/PersonnelMap`。删除旧画布、缩放、连线及单双模式布局，重新编写界面样式。等级栏显示当前人数、真实承接资源、需跟进与计划待落实人数。容器显示已落实、计划和共享空位，未落实安排单独提示。空闲资源可显示或隐藏。

点击容器在并排详情查看人员、资源条件与实际流动。跨等级流向、同级调动和静态联系分组保留，可查看对应人员与历史，原编辑和调动接口不变。支持搜索、等级筛选、分享、旧链接和前进后退。手机默认展开有待跟进事项的等级，可展开其他等级，详情移到工作区前部；Escape 关闭详情并恢复原容器焦点。

工作清单与历史按需展开；日期范围只用于已登记流动，不伪装成当前库存的历史快照。真实接口只使用临时虚构资料，结束后删除档案、停用资源并撤销验收凭据。
