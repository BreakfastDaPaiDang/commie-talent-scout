- 静态首页原先不经过 Worker 安全头中间件，现用 `public/_headers` 补齐并通过云端实际响应检查。用量脚本实际运行成功，CPU 限制 2,000 ms，日志采样和查询参数脱敏已配置；每日备份/用量任务已提交。

## 调用拒绝分类修复

真实检查发现 SSE 响应先返回时，业务回调会在等待响应正文期间完成。旧逻辑随后用通用 `INVALID_TOOL_REQUEST` 覆盖 `ARCHIVE_CLOSED` 等已确定拒绝码。现于正文读取后重新核对回调结果，只对没有业务结果的协议错误应用通用分类。

`verify-mcp-error-journal.mjs` 在修复前复现失败，修复后分别验证关闭拒绝保留业务码、缺少参数仍保留协议分类。已有 6 项日志脱敏与任务审阅测试继续通过。

## 尚未验收完成

- GitHub 的 deploy 任务实测停在缺少 `CLOUDFLARE_API_TOKEN`，未进行云端写入。本机 Wrangler OAuth 没有签发账户令牌的权限；浏览器连接也未能操作 Cloudflare 管理页。需维护者按运维文档填入 CI 专用 Secret，再运行自动发布和每日任务。
- 已验证浏览器 `--no-proxy-server` 下的正式操作，但仍待确认当前网络运营商及是否有系统 VPN/TUN；不把此结果直接标成“大陆成员无代理验收完成”。
- SDK 客户端不是实际 Codex。此前真实 Codex 的 `delete_observation` 遇到 `MCP tool call requires approval, but approval policy is never`；本地图片读取命令被客户端策略拒绝。需要在能够逐次批准操作的真实客户端完成剩余图片、删除恢复、词库维护和正式环境闭环；没有改低工具风险标记来绕过。
- 每日阈值是运行指标，不是月度账单上限。每月预算提醒尚未验证；首版里程碑验收通过前不创建最终 Release。
