# 材料压缩与浏览器恢复

2026-09-09 · Issue #28、#29。

材料整理现在按记录目的选择变化、双方行动和必要判断，区分已完成、报告完成、要求、计划和附条件安排。标签不适配时说明维度缺口与候选定义，供用户审阅。补齐 14 个仍保持初始状态的类别边界，保留定义历史和用户修改；标签查询及当前绑定返回类别说明，新关闭快照冻结当时说明，旧快照不倒填现行含义。

浏览器侧保留改密成功后直接进入工作台；密码输入增加显示/隐藏，原型与正式站共用组件。页面从历史恢复或重新激活时重新核对会话，网络失败不当作退出，过时响应不能覆盖新登录。认证请求禁止缓存，恢复后的未登录表单清空旧密码；普通切回页面不清除正在输入的内容。

验证：新增两项真实 SQLite 测试覆盖类别补充、用户修改保护及冻结含义；会话恢复测试覆盖禁止缓存、401、暂时故障及迟到响应。现有服务检查通过，迁移总数同步为 14；DOM 6 项通过。真实 staging API 与新版浏览器界面联验 5 项通过，另检查桌面/手机密码框宽度和截图。已部署 staging 的 MCP 指南和类别说明查询 2 项通过。正式发布沿用自动检查、备份、迁移、部署与冒烟。

本轮没有再次运行多轮真实 Agent 对话，也不把规则发布等同于所有模型的压缩质量已达标。用户报告的浏览器问题在关闭页面后消失，但未取得当时的提交内容，不能据此确定为缓存或自动填充。网站不能替用户修改密码管理器中的已保存密码。
