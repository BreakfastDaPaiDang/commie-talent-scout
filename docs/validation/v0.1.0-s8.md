搜索覆盖名称、联系方式及未删除观察的当前正文，命中较早的观察时返回其 ID 和命中附近摘要。历史版本不混入普通搜索。可组合全部/我负责/有未读、当前业务状态、当前关联成员、开启/关闭；“我负责”仅当前工作状态明确绑定本人。网页按成员和人物/组织页面保存搜索与筛选，提供清除、空结果和失败重试。选中命中项独立读取对应观察，不受原列表筛选和已加载页数限制。

未读按成员和事件保存，排除自己动作及账号创建前事件；编辑、删除、恢复各产生独立事件。摘要与未读导航不确认阅读。实际内容返回绑定成员、凭证、事件及观察状态版本的 24 小时票据；确认时以原子 SQL 重新检查当前状态、可见性及有效期。跨凭证、伪造、过期、陈旧版本不能确认；相同票据重试幂等，阅读不会更改档案版本或活动排序。Web 与 MCP 共用个人标记。隐藏记录派生的标签事件在 SQL 分页和计数之前过滤，避免内容或数量旁漏。

网页观察正文起始区域在前台进入视野后自动确认，长卡片以正文开头为边界。后台、弹窗遮挡、屏幕外和失败内容不确认；图片正文等待起始图片载入。折叠事件展开后才确认，明确跳转的事件展开其内容。失败自动重试，版本变化重新读取；离开卡片时仍会同步已经发出且成功完成的确认。本次未读队列固定事件上界、保留已阅位置，下一处优先同档案，包括未加载页中的同档案更新，再跨人物/组织继续。以上为已实现并通过类型检查/构建的路径，尚不宣称实际页面操作通过。

本地和云端 `scripts/verify-reading-search.mjs` 各四组通过：旧观察命中与转义、组合筛选；摘要不确认、不同成员/凭证隔离、重试与活动不变；新编辑、旧票据、Web/MCP 共享、本人及账号前事件排除；删除正文与依赖标签隐藏、关闭和删除直达上下文、跨库快照分页及最大 limit=100。云端完成于 2026-09-08T15:13:17Z，未发生结果不明恢复。
