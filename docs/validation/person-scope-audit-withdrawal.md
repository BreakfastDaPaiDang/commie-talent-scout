# 社员范围与撤回审核验收（Issue #69）

2026-10-02，针对社员档案混入外部人物列表，以及撤回审核后自动审核任务仍开启的反馈。

## 修复结果

- 网页外部人物列表使用 `person_scope=external`，社员列表使用 `person_scope=members`。服务端在计数、分页之前执行同一范围条件，与搜索、业务状态、当前关联成员、关联我、未读及开关筛选共同生效。
- 兼容现有人物状态存储：`已加入待对接`、`已入伙` 属于社员范围，其余人物属于外部范围；共享 `memberStatuses` 定义这两个值。API 未提供范围时仍查询全部人物，组织列表和管理员回收列表保留原范围。
- 仍使用同一档案、ID 与旧链接。社员页直接建档保持开启，不生成审核或对接任务；社员不能再次提交外部人物审核。
- 人物从引荐中／人事审核退回观察、个人接触、外部社友或已弃用时，集中生命周期规则取消开启中的自动审核任务。状态、取消原因、任务历史和请求收据在同一事务中提交；保留负责人，不处理已完成审核或独立手动任务。
- 反向操作也一致：取消当前自动审核任务且档案仍处于本次审核时，沿用最后一次状态历史中的引荐前关系及其原关联成员。没有可确认的历史、档案已关闭／删除或已取得社员身份时不推定退回；取消权限沿用创建者仅取消未领取任务、管理员可取消已领取任务。
- MCP 使用同一范围条件和生命周期规则，新增筛选进入调用记录；指南同步说明范围及已入伙保持开启。

没有数据库迁移，没有另建人物档案或改页面布局。这是现有身份表达的局部修复，不宣称完成 #60／#62 的全部身份与任务需求。
