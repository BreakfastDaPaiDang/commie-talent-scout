## 维护方式

新增需求先更新 PRD 或对应专题，再同步受影响的 Issue。产品规则以 PRD 和其引用的专题为准；实现机制不反向改变权限或用户意图。服务指南从这份基线实现，不要求外部 Agent 自行读取仓库文档。

Issue 发布后，实施状态在 GitHub 管理，本地只保留索引、实施顺序及基线。完成一项应交付可用路径和对应证据；不能只完成数据表或工具定义就关闭业务任务。v0.1.0 里程碑与 Release 分开：现在建立里程碑规划工作，正式上线验收完成后才发布版本。
