# 统计仪表盘

已上线。登录后从顶栏“统计”或账号／手机工具菜单进入 `/statistics`。

## 使用

- 用户优先：按观察记录原作者统计，同名成员以账号区分。
- 标签优先：按标签库里的标签统计，显示完整“类别：名称”。
- 人物／组织优先：按档案类型统计，也可在其他分组下筛选档案类型。

支持自选日期、近 7／30／90／365 天、日／周／月粒度、名称搜索和累计折线。默认对比前五组，可以在分组明细中选择最多六条折线，逐期数据表提供精确数值。一次最多展示前 50 组；超过时会明确提示，可搜索其他分组。概览总数涵盖整个筛选结果，不局限于这 50 组。

## 统计口径

“记录”指已发布且未删除的观察记录，以原作者和首次提交时间计数，不把编辑版本、草稿、系统操作、标签定义创建或文件上传混作观察记录。日期采用东八区；起止日期均包含在内，最长 366 天。周从星期一开始，首尾不满一个周期时只计所选日期；没有提交的周期补零，累计只从区间开始累加。

标签绑定在档案上。标签分组统计带有该标签的档案中的观察记录，不仅是标签依据引用的记录。开启档案使用当前可见绑定，关闭档案使用关闭快照；以后调整标签可能改变历史记录的分组归属，不能解释为当时新增标签的次数。停用标签保留统计，已删除的标签和类别排除。没有可见标签的档案归入“未标注标签”。

同一记录在一个分组内只计一次，跨标签可能重复归属，因此不能将各组数字相加作为总数。总记录数、提交成员数和涉及档案数分别去重；“占去重总数”跨组相加可能超过 100%。

已删除档案和观察对所有角色均不计入。绑定依据的可见性沿用现有 `TagState` 规则，不通过统计泄露当前无权读取的标签依据。冻结成员的既有提交仍归属于原成员。

## 实现与验证

共享界面：`app/ui/StatisticsDashboard.tsx`；正式适配器：`app/client/StatisticsPage.tsx`；原型使用独立虚构数据适配器。鉴权接口 `GET /api/statistics` 在数据库中聚合，不依赖列表分页，也不写阅读回执；`GET /api/statistics/link` 返回统计页链接，供复制或打开。未增加数据库迁移或图表依赖。

请求参数：`from`、`to`、`group=user|tag|type`、`interval=day|week|month`、`archive_type=all|person|org`、`search`。非法日期、倒置区间或超过 366 天返回 400。查询结果最多 50 组，`groups` 返回实际组数。
