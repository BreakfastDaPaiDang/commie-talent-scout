# MCP 的 Agent 使用体验设计

2026-09-09 · 根据用户反馈修正默认行为，Issue #26。

## 核心角色：先做顾问，再做操作助手

Agent 应主动结合用户目标、已有档案和新材料做判断，给出值得采用的建议。用户不必先把聊天拆成字段，也不必点名工具；Agent 不能只复述材料、列工具清单或把“该怎么处理”全部丢回用户。

建议应回答本次最有用的问题：哪些新变化值得留下，哪些重复或无关内容应省略，哪些标签应增加、移除或保持，下一步怎样做有帮助。给出推荐及简短事实理由，按价值排序。允许建议不发、不改或延后，不为显得主动制造信息或追问；仅在缺项会改变方案时询问。

## 默认路线：判断、推荐、审阅、执行

1. 辨认对象，读取相关旧观察、标签定义和依据。区分同名对象及各个发言者，不把他人的能力归给当前人物。
2. 比较新旧材料，找出影响认识的新增事实和条件。区分本人自述、他人转述和判断；材料未提旧标签不等于失效。
3. 先说明推荐的重点和取舍，再给可审阅的精简观察草稿，以及分开的标签增减/新建建议与理由。不把所有分析写进观察，也不机械逐项询问工具授权。
4. 等用户看过方案并确认。修改草稿或继续讨论不等于发布；只同意观察就只发观察，只同意部分标签就只执行该部分。
5. 执行最后确认稿，不自行扩写；核对结果，简短报告实际变化、对象链接和未完成部分。

“整理资料”“整理进档案”“补观察和标签”默认授权读取、分析和提出方案，不能自动发布观察、变更绑定、创建词条/类别或顺手修改基础资料。连接凭据和客户端工具许可也不是内容确认。用户已确认当前具体方案、已提供最终正文并明确要求按原文发布，或明确要求本次免预览直接执行，则沿用授权，不重复确认。

观察草稿通常几句话即可，保留关键新事实、来源、时间范围和会改变理解的限制，合并重复，删去无关人物、操作过程、打标理由和自我说明。不硬套篇幅模板，不为压缩丢掉必要条件。请用户看看重点和措辞是否合适，允许删改或不发。

## 一个自然的顾问式回应

虚构材料：“我上周交付了两条访谈剪辑。以前管理的账号交给别人了。下个月备考，只能周末参与。”旧档案已记有剪辑经历和账号管理权限。

Agent 读取旧依据后可以推荐：“这次最值得补的是账号权限已交接和下个月的参与时间；剪辑经历已有，不必重复铺陈。建议移除该账号对应的资源标签，保留剪辑技能，交接资源不代表技能消失。”再给精简草稿，并在正文外列出适用的标签建议。

只看教程不能推定已经掌握技能；阶段性可用时间不能推成长期不可靠。已给作品链接时可建议随草稿保留，没给时说明补链接对核实交付的用途，不因作品数量推定专业等级。若词库缺少有用的新特征，主动建议合适名称、类别和通用描述，用户确认后创建和绑定。

用户说“太长，只保留后两项”时，应重写草稿供审阅；说“按这版发布，标签先不动”时，只发布这版观察。这样的建议帮助用户判断，而不是增加一串形式审批。

## 服务如何支持这一角色

MCP instructions、身份返回、主题指南和关键写入工具共同提供顾问与审阅规则，不依赖用户阅读仓库或首次消息永久留在上下文。连接提示词保留简短角色提示；完整业务知识从 MCP 按需取得。已连接客户端可能缓存服务说明，更新后需重新读取指南或重连。

这是外部 Agent 的行为指导，服务端权限仍逐次校验；服务端不能凭工具调用证明用户已经审阅聊天草稿，不用模型自填的布尔值冒充人工确认，也不增加网页审批流。

## 验收与改进

使用同一个真实 Codex 对话逐轮验收：泛化整理请求主动给有依据的推荐且不写；要求精简仍不写；仅确认观察就只发布最后草稿；随后确认标签才执行相应建议。逐轮核对业务状态和调用记录，并人工阅读建议是否抓住重点、是否具体、有无多余追问，不能只检查工具成功或“没有写入”。

请求及任务留存设计见 [外部 Agent 请求留存](./mcp-request-data.md)。未提交的外部聊天与反应不可见，不能从服务调用猜测用户满意度。历史版本验收记录保留当时语义，新的行为以本文件及 [服务指南](./mcp/agent-guide.md) 为准。

## 按记录目的压缩变化与行动（Issue #28）

先判断哪些信息会改变认识、帮助关系接续或影响后续安排，再选取少数新增重点；不按聊天话题逐段缩写。主动建议记录用户与对象双方的行动、决定及结果，区分已完成、本人报告完成、要求/建议、计划/意向和附条件承诺。提出引荐不等于已引荐，要求修改不等于已完成；不强制每条记录附行动区。判断应明确属于谁，未来设想与当前实践的差别不自动升级为言行矛盾。

标签承载以后检索或协作时反复有用的维度，一次事件通常留在观察。读取标签及类别描述，区分已有技能、职业方向、参与意向、当前实践与资源；现有类别不适配时说明维度缺口、建类价值及候选定义供审阅，不硬塞，也不直接放弃分析。初始类别边界见 [词库](./tag-catalog.md)，未自动增加参与意向或当前实践类别。
