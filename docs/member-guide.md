# 成员上手指南

正式入口：**[scout.dapaidang.org](https://scout.dapaidang.org)**。当前版本 v0.1.1，电脑和手机均可使用。

## 第一次登录

向管理员申请账号，用收到的账号和临时密码登录，按提示设置自己的密码后进入工作台。系统没有自助注册。忘记密码时联系管理员重置；不要在群里发送密码。

右上角“猎头账号”用于维护自己的账号资料。人物与组织档案是大家共同关注的对象，与登录账号是两件事。

## 先找到对象，再留下进展

1. 打开“人物”或“组织”，搜索名称、联系方式或观察正文。先看已有档案，避免重复创建；同名时结合资料确认是不是同一个对象。
2. 打开档案，先读最近观察、状态、负责成员和标签依据。需要补联系方式、资料链接、状态或成员时，进入“编辑档案”。
3. 在“新的观察记录”中写下新情况，必要时附图片，再点击“发布记录”。几句话说明发生了什么、对方和我们各做了什么、还有什么待确认即可。

例如，虚构的一条观察可以写：“9 月 9 日沟通后，对方表示愿意参与字幕校对；已发出一份样例，对方尚未确认试做时间。”把已完成的行动和待确认事项分开，方便下一位成员接续。

未发布内容会自动保存为个人草稿，看到保存成功后再离开。发布后的观察会进入共同记录，修改会保留旧版本。普通成员可以修改、删除和恢复自己写的观察；管理员可以处理其他成员的记录，均须档案处于开启状态。

## 状态与负责成员

按实际情况选择状态，不必按固定顺序逐级推进。

| 档案 | 状态 | 是否必须指定负责成员 |
| --- | --- | --- |
| 人物 | 视奸观察、个人接触 | 可选关联成员 |
| 人物 | 引荐中（待人事组接触）、人事审核、已加入待对接 | 必须，可多人 |
| 人物 | 已入伙、已弃用 | 关闭档案 |
| 组织 | 视奸观察、个人接触 | 可选关联成员 |
| 组织 | 组织交流 | 必须，可多人 |
| 组织 | 已弃用 | 关闭档案 |

“已加入待对接”表示仍有对接工作，“已入伙”表示已经完成。关闭后记录保留并只读；需要继续维护时重新开启。删除整张档案由管理员处理，和业务上的关闭分开。

“关联我”展示当前关联成员包含自己的档案，不限工作状态。历史状态的关联不计入；搜索、状态、开启／关闭等筛选仍然生效。

## 标签与绑定材料

标签用于后续查找和理解对象。优先复用已有的“类别：名称”，查看它的定义，并为本次绑定留下具体依据。公共标签定义会供其他档案使用，修改时先看影响范围。不要把一次行动或尚未证实的猜测写成稳定特征。

文件放在档案的“绑定材料”页签，可以选择或拖入多个文件、下载，常见图片和 PDF 可以预览。人物默认总额度 100 MB，组织 200 MB，单文件最大 100 MB；空间不足时先整理不再需要的材料，或联系管理员调整额度。材料移入回收站仍占空间，彻底删除后才释放。

上传者与管理员可以维护材料名称和说明、删除、恢复或彻底删除；其他成员可以读取有效材料。关闭档案中的材料只读。

## 两种提醒怎么看

| 提示 | 含义 | 怎么处理 |
| --- | --- | --- |
| 有更新 / 未读更新 | 有你还没读到的新变化 | 打开档案即清除当时已有未读，之后的新变化仍会提醒 |
| 需更新或关闭 | 开启档案长期没有实际更新 | 核实近况后补实际进展、维护资料或状态；结束跟进时关闭 |

开启的人物和组织超过 **30 天**未更新会置顶报警；人物的**引荐中、人事审核、已加入待对接**三个状态缩短为 **7 天**。超期档案中最早到期的排在前面，仍遵循当前搜索和筛选条件。

实际更新后重新计时，关闭后解除。查看、自动已读、未提交草稿和没有内容变化的保存不会清除报警。两种提醒可以同时存在，无需为了消除报警写空记录。

打开档案后，不必滚动或展开每条内容来清除未读。“下一处未读”直接进入另一张有更新的档案；已阅条目保留在本次队列，刷新队列后纳入后来的更新。

## 可选：让 Agent 帮忙

打开“Agent 接入”，点击“复制提示词给 Agent”，把正文发给自己要授权、且支持 MCP 的 Agent。复制内容包含个人连接凭据，只发给该 Agent，不转发到群或公开 Issue。需要停用时在连接管理中撤销。

连接后可以这样说：

> 帮我查一下这个对象有没有档案。结合已有记录和下面的聊天，给我一份简短的观察草稿和标签建议，我看过后再发布。

Agent 会在你的账号权限和本次授权内工作。先核对它识别的对象、草稿与依据，再确认需要执行的部分。网页仍可完成全部日常操作，不需要先接入 Agent 才能使用系统。

## 遇到问题

先记下操作步骤、发生时间和页面提示，联系管理员。提交公开 [GitHub Issue](https://github.com/BreakfastDaPaiDang/commie-talent-scout/issues) 时，用虚构内容描述问题，截图先遮住内部资料；不要贴密码或 Agent 接入正文。

普通档案和有效材料供登录成员共同查看，适合存放组织协作所需的信息；请按这个范围决定要发布的内容。
