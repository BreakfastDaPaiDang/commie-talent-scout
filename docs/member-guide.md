# 成员上手指南

正式入口：**[scout.dapaidang.org](https://scout.dapaidang.org)**。当前版本 v1.0.0，电脑和手机均可使用。

## 第一次登录

向管理员申请账号，用收到的账号和临时密码登录，按提示设置自己的密码后进入工作台。系统没有自助注册。忘记密码时联系管理员重置；不要在群里发送密码。

右上角“猎头账号”用于维护自己的账号资料。人物与组织档案是大家共同关注的对象，与登录账号是两件事。

## 先找到对象，再留下进展

1. 打开“外部人物”“社员”或“组织”，搜索名称、联系方式或观察正文。先看已有档案，避免重复创建；同名时结合资料确认是不是同一个对象。
2. 打开档案，先读最近观察、状态、负责成员和标签依据。需要补联系方式、资料链接、状态或成员时，进入“编辑档案”。
3. 在“新的观察记录”中写下新情况，必要时附图片，再点击“发布记录”。几句话说明发生了什么、对方和我们各做了什么、还有什么待确认即可。

例如，虚构的一条观察可以写：“9 月 9 日沟通后，对方表示愿意参与字幕校对；已发出一份样例，对方尚未确认试做时间。”把已完成的行动和待确认事项分开，方便下一位成员接续。

未发布内容会自动保存为个人草稿，看到保存成功后再离开。发布后的观察会进入共同记录，修改会保留旧版本。普通成员可以修改、删除和恢复自己写的观察；管理员可以处理其他成员的记录，均须档案处于开启状态。

## 查找已关闭档案

外部人物和组织默认保留所有符合其他筛选条件的开启档案，以及最近 30 天关闭的档案。列表上方显示“已关闭档案：最近 30 天”；点击它或“筛选”，可切换最近 90 天、全部。“重置筛选”恢复默认 30 天。

找较早关闭的档案时，先将范围改成“全部”，再搜索。时间从最后一次关闭算起，打开阅读不会延长展示期限。超出范围只是从列表隐藏，旧链接仍可打开；缺少关闭时间的历史记录也可在“全部”中找到。

## 档案身份与状态

外部人物切到“人事审核”会生成待领取审核任务；切到“已加入待对接”会生成对接任务，但仍在外部人物页。确认“已入伙”后，同一档案进入社员页，资料、观察和历史保留，档案继续开启。

社员基本状态为“可接工作、请假、失联”，由人事组维护，默认可接工作；没有单独关闭社员档案的操作。退出或转为外部社友时，按实际身份变化维护。组织的“组织交流”可关联多位负责成员。

档案关联人员与任务负责人分别维护。任务由领取人负责，改档案状态或写观察不会自动完成任务。

## 领取和交付任务

任务页分为“任务簿”和“看板大厅”，默认高优先级在前：P0 → P1 → P2。看板的待领取、进行中显示全部开启任务；已关闭默认最近 30 天，可切换 90 天或全部。搜索和新建在页头。

领取后可提交交付、延期，或放弃回到待领取；逾期仍保持开启。把真实跟进结果写入关联档案，再提交任务交付，可以引用已有观察。联系不到也可如实完成，不要求必须收到回复。关闭后只读，继续工作需显式重开。

档案主页面显示全部开启的关联任务，点击可打开详情，也能查看已关闭任务。评论和历史较多时，点击“加载更早记录”继续阅读。

早纪每月自动为正式社员建立一项人事跟进任务，包括请假、失联的社员；月底截止，上月未完成不妨碍新月生成，同月不会重复。

## 消息

铃铛进入统一消息列表，包含任务提醒与档案更新。“全部标为已读”确认当前已有消息；操作期间新到的消息继续保留未读。读消息不会接取、延期或完成任务。

## 标签与绑定材料

标签用于后续查找和理解对象。优先复用含义合适的“类别：名称”；仅适用于一个对象的特征也可以新建标签。词义说明解释标签含义，具体来源、适用范围和判断原因写在绑定依据中，最近确认时间可在标签详情查看。公共标签定义会供其他档案使用，修改时先看影响范围。不要把一次行动或尚未证实的猜测写成稳定特征。

文件放在档案的“绑定材料”页签，可以选择或拖入多个文件、下载，常见图片和 PDF 可以预览。人物默认总额度 100 MB，组织 200 MB，单文件最大 100 MB；空间不足时先整理不再需要的材料，或联系管理员调整额度。材料移入回收站仍占空间，彻底删除后才释放。

上传者与管理员可以维护材料名称和说明、删除、恢复或彻底删除；其他成员可以读取有效材料。关闭档案中的材料只读。

## 两种提醒怎么看

电脑端点击右上铃铛进入未读更新，角标显示未读数量；手机端从右上工具菜单进入。

| 提示 | 含义 | 怎么处理 |
| --- | --- | --- |
| 有更新 / 未读更新 | 有你还没读到的新变化 | 打开档案即清除当时已有未读，之后的新变化仍会提醒 |
| 需更新或关闭 | 开启档案长期没有实际更新 | 核实近况后补实际进展、维护资料或状态；结束跟进时关闭 |

开启的外部人物和组织超过 **30 天**未更新会置顶报警；外部人物的引荐中、人事审核、已加入待对接状态为 **7 天**。社员不使用外部档案的超期关闭提醒。超期档案中最早到期的排在前面，仍遵循当前搜索和筛选条件。

早纪会为符合提醒条件的外部档案生成接触跟进任务，同轮提醒或已有同类开启任务不叠加。实际更新后重新计时，关闭后解除。查看、自动已读、未提交草稿和没有内容变化的保存不会清除报警。两种提醒可以同时存在，无需为了消除报警写空记录。

打开档案后，不必滚动或展开每条内容来清除未读。“下一处未读”直接进入另一张有更新的档案；已阅条目保留在本次队列，刷新队列后纳入后来的更新。

## 可选：让 Agent 帮忙

打开“Agent 接入”，点击“复制提示词给 Agent”，把正文发给自己要授权、且支持 MCP 的 Agent。复制内容包含个人连接凭据，只发给该 Agent，不转发到群或公开 Issue。需要停用时在连接管理中撤销。

还没有 Agent 时，页面的新手推荐卡片提供 DSH 桌面版下载按钮；展开“查看安装与接入步骤”了解 API 余额充值和接入方式。

连接后可以这样说：

> 帮我查一下这个对象有没有档案。结合已有记录和下面的聊天，给我一份简短的观察草稿和标签建议，我看过后再发布。

Agent 会在你的账号权限和本次授权内工作。先核对它识别的对象、草稿与依据，再确认需要执行的部分。网页仍可完成全部日常操作，不需要先接入 Agent 才能使用系统。

## 遇到问题

先记下操作步骤、发生时间和页面提示，联系管理员。提交公开 [GitHub Issue](https://github.com/BreakfastDaPaiDang/commie-talent-scout/issues) 时，用虚构内容描述问题，截图先遮住内部资料；不要贴密码或 Agent 接入正文。

普通档案和有效材料供登录成员共同查看，适合存放组织协作所需的信息；请按这个范围决定要发布的内容。

## 辅助工具：导出 QQ 聊天

在右上顶栏或账号菜单（手机端为工具导航）打开“辅助工具”，按页面教程下载最新 QCE Framework 版，在“QQ导出工具”等固定文件夹完整解压，退出 QQ 和旧后台后运行 `napiLoader.bat`。正常登录后，QQ 与导出后台可以一起使用。选择好友或群聊、时间范围并导出 TXT，把需要的内容复制给 AI 即可。

接入猎头 MCP 且能够操作本机的 Agent 也可以按 `qq_export` 指南协助启动与导出。你可以说：“帮我导出与某人最近一个月的聊天并整理。”需要退出正在运行的 QQ 时，Agent 会先说明并征得同意；扫码和手机确认由你完成。

### 网页留存与临时分享

辅助工具页还提供互联网档案馆（Wayback Machine）与 Sixin.cc。输入原网址查询已有历史副本，按年份和日期打开；也可使用 Save Page Now 提前保存仍可访问的公开网页，检查结果并保留存档链接。已删除的页面需要此前已有存档才可能找回，不能恢复从未保存的内容。Sixin.cc 把文字生成私信链接；先确认阅读后销毁还是定时销毁，再复制链接给收件人。使用阅读后销毁时不要自己先打开链接；它不能防止收件人截图或复制。
