# Agent 接入提示词

接入页保留短说明与“复制提示词给 Agent”按钮。首次消息只负责连接、临时/持久选择和核验；业务任务与规则由 MCP 提供，避免依赖第一次聊天里的长手册。

复制正文的唯一模板见 [bootstrap-prompt.txt](../prototypes/frontend/src/bootstrap-prompt.txt)，前端直接读取该文件。正式应用填入真实服务地址及本人认证入口，不嵌入个人凭证；当前原型填入“尚未提供”，不能实际接入。

模板要求 Agent 先检查已有连接；用户尚未选择时询问是否需要持久配置，已明确选择则继续。选择持久配置后，说明客户端及保存范围，分别检查连接设置、认证来源和新会话可用性。“配置已保存”和“新会话已验证”分别报告。

连接完成后，从 MCP 获取系统用途、当前身份、实际能力与本次任务指南。有现成任务或材料就继续处理；只请求连接时给一个简短的使用入口。服务自带内容可以重新取得，不代表所有 Agent 在压缩上下文后都会自动记得或读取。

产品任务与主动帮助的设计见 [MCP 的 Agent 使用体验](./mcp-agent-experience.md)；原长提示词中的业务规则已迁入 [服务内 Agent 主题指南](./mcp/agent-guide.md)。配置和服务承载细节见 [MCP 对接设计](./mcp-design.md)。正式体验尚待实现，不能把技术探针具备部分指南视为产品已完成。
