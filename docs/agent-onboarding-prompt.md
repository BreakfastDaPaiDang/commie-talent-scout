# Agent 接入提示词

接入页保留短说明与“复制提示词给 Agent”按钮。首次消息默认只负责立即连接与最小身份核验；业务任务与规则由 MCP 按需提供。

2026-09-09 用户修正接入要求：点击复制时自动创建当前成员的专用 MCP 凭据，复制的正文必须包括真实地址与完整认证配置，使没有浏览器能力的 Agent 也能接入。唯一模板见 [bootstrap-prompt.txt](../app/shared/bootstrap-prompt.txt)。认证配置用通用 `mcpServers` JSON 表达 HTTP 地址和 Authorization 请求头，Agent 按所在客户端转换格式；连接管理网址仅供成员撤销，不是 Agent 的前置认证步骤。

正式站与原型共用 `app/ui/AgentHandoff.tsx`。正式按钮创建 90 天连接，凭据只在当前页面内存保留；重复复制和剪贴板失败后的重试复用同一份凭据，撤销后再次复制则换发。“为另一个 Agent 复制”创建独立连接。剪贴板不可用时显示可选中正文；成功复制后不常态显示认证值，不写入 localStorage/sessionStorage。原型只说明需在正式站操作，不生成假凭据。

2026-09-10（Issue #42）用户反馈：已提供地址、凭据与授权，Agent 仍花费六分半巡检配置，最后只询问持久化而没有连接。旧模板“先检查并询问”的前置要求已移除，服务端 connections 指南与初始化说明同步修正。

现在优先使用已有原生 MCP 工具；没有则以现成 HTTP/终端能力初始化并调用 whoami。成功核对身份后立即反馈，仅连接时不扫描业务档案、不加载全部指南。默认先完成当前会话，持久化仅在用户明确要求时实施；已给出范围不重复询问。真实失败后针对性排查，暂时性网络错误最多重试一次，约 30 秒未完成先反馈阻塞；不绕过客户端权限。

只有执行了持久化才报告保存位置、认证来源及新会话验证。客户端配置管理是另一项操作，例如 [Codex 官方命令文档](https://learn.chatgpt.com/docs/developer-commands#codex-mcp) 中的注册与配置管理；不能把它作为用户已授权的当前 HTTP 身份验证的必经步骤。

连接完成后，从 MCP 获取系统用途、当前身份、实际能力与本次任务指南。有现成任务或材料就继续处理；只请求连接时给一个简短的使用入口。服务自带内容可以重新取得，不代表所有 Agent 在压缩上下文后都会自动记得或读取。

产品任务与主动帮助的设计见 [MCP 的 Agent 使用体验](./mcp-agent-experience.md)；业务规则位于 [服务内 Agent 主题指南](./mcp/agent-guide.md)。配置和服务承载细节见 [MCP 对接设计](./mcp-design.md)。旧 S2 验收使用预先准备的认证，不能替代 Issue #25 的“从实际复制正文开始、无浏览器、无预配置 MCP、新会话可用”验收。

业务默认先做顾问：结合已有档案主动判断重点、标签取舍及下一步，给出有理由的推荐和精简草稿，用户审阅确认后执行。连接认证不等于业务内容确认；详细规则由 MCP 提供。

Issue #42 验证：类型检查、77 项测试与构建通过；本地及已部署 staging 的实际复制流程通过，独立无浏览器 MCP 客户端仅凭复制正文成功调用 whoami，覆盖剪贴板失败重试、独立凭据及撤销后换发。此次没有重跑外部模型的完整对话，以上结果证明文案与接入链路已修正，不代表能保证所有客户端的执行速度。
