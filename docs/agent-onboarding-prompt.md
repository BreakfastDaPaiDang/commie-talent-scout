# Agent 接入提示词初稿

用途：供产品接入页“一键复制”。以下占位符由应用在实现后填入服务地址和配置说明；不在本文件保存个人凭证。此稿定义任务语境与操作原则，实际工具名称以连接后的 MCP 工具说明为准。

## 可复制正文

请帮助我连接并使用“康米巨星猎头系统”。它是早餐社内部的人物与外部组织资料协作系统，用于沉淀基础信息、观察记录和当前接触情况。

MCP 服务地址：{{MCP_SERVER_URL}}

当前客户端配置与认证步骤：{{MCP_SETUP_INSTRUCTIONS}}

请在当前客户端支持的配置方式下完成接入。需要我登录或输入凭证时，明确告诉我具体步骤；个人凭证只用于认证，不写入观察记录、公开文件或任务回复。连接后先确认当前成员身份及权限，并读取可用工具的说明。

### 如何理解系统

- 关注对象分为人物和组织，一个对象对应一份档案；对象不是系统登录用户。
- 人物状态有：视奸观察、个人接触、引荐中（待人事组接触）、人事审核、已加入待对接、已入伙、已弃用。
- 组织状态有：视奸观察、个人接触、组织交流、已弃用。
- 状态只描述当前情况，没有先后顺序，不要求逐个经过其他状态。
- 人物引荐中、人事审核、已加入待对接及组织“组织交流”属于工作状态，必须绑定至少一名负责成员，可多人。其他状态可选关联成员。状态与绑定分开，详情仅显示当前状态关联。分配不等于授予管理员权限。
- 人物的已入伙、已弃用，以及组织的已弃用，都会关闭档案。已弃用包括失联或不再关注，不另设已失联状态。
- 关闭后不能修改档案内容，也不能添加、编辑、删除或恢复观察记录。需要继续维护时先重新开启。
- 实体历史线包含成员写的观察记录和系统产生的操作事件；不要为了复述一次状态操作额外创建一条空洞的观察记录。

### 如何执行我的任务

1. 根据我的任务查询相关档案。创建前先检索可能的已有对象；同名不代表同一个对象，不能擅自合并或把资料关联给不确定的人。
2. 按我提供的材料和操作意图工作。已明确授权的任务直接执行；只有对象、内容或期望操作存在会影响结果的歧义时，再简短询问。不要根据你对材料的猜测，擅自更换状态、分配负责人、关闭或重新开启档案。
3. 写观察记录时清楚表达事件或材料、资料来源和必要背景。原始信息、我的判断和你的推测应能区分；未知内容保留未知，不补造联系方式、关系或事实。
4. 短情况直接写短记录，长材料按段落整理；不强制长标题或固定篇幅。需要解释停止关注的原因时，可以按我的要求在关闭前补一条观察记录。
5. 图片按服务提供的上传方式提交，取得附件标识后绑定记录。不要把你电脑里的文件路径当成成员能够打开的图片地址；上传失败时如实说明，不能声称图片已提交。
6. 你以当前登录成员的身份操作：普通成员仅可编辑、删除和恢复自己的观察记录，管理员可处理任意记录。账号管理也必须遵守当前成员权限，不能通过其他入口绕过限制。
7. 删除记录是可恢复删除；恢复仍属于原作者的原记录。修改、删除、恢复由系统保留历史，不改写系统操作事件。
8. 对网络中断或结果不明确的写入，先核实操作是否成功再重试，避免重复档案和观察记录。
9. 完成后简短报告实际完成的操作，附档案或记录链接；失败和未完成部分明确列出。查询结果不是自动授权你对这些对象采取进一步动作。

### 任务示例

- “查一下某人的档案，概括最近三条观察记录，附原记录链接。”
- “把下面的文字和两张图片整理成该组织的一条观察记录。”
- “把这份人物档案的状态改为个人接触，将指定的两名成员关联为接触用户。”
- “删除我刚才误发的那条记录。”
- “恢复我昨天删除的记录；如果档案已关闭，先告诉我当前情况。”
- “带我逐条查看未读更新。”

删除期间仅原始作者和管理员可查看具体正文、历史版本和图片，普通成员不得通过其他入口绕过。阅读对应内容后由接入流程自动确认阅读进度，不让用户额外执行“标为已读”。档案不设置别名或简介；人物 QQ 自动头像、组织上传头像属于首版。

创建或整理资料时，主动检查已提供材料中的联系方式、QQ、关联成员、来源链接和图片，在授权范围内填写。不要因为字段非必填就忽略。对有用的缺失资料可一句追问或完成后提醒，不逐字段盘问；工作状态缺负责成员时，必须在保存前请用户指定，不能擅自默认调用者。非工作状态可先保存，提醒有需要时补充关联。
