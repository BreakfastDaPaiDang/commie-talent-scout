# 1.1.1 发布与回退

在 1.1.0 人员认可功能上修正夜间确认框：引用区使用主站 `--wash`、`--ink`，边框使用 `--line`，不再落入浅色固定值。共享原型和正式界面同时生效，操作与业务规则不变。

无新增迁移、依赖或 MCP 参数变化；健康接口、MCP 服务和包版本统一为 1.1.1。真实 HTTP/MCP 验收补充 1440/390px 日夜确认框、无横向溢出和引用正文至少 4.5:1 的对比度检查。

按现有 PR 检查、主分支自动备份发布和资源字节验证流程上线。本补丁可单独回退到 1.1.0（28a4ede），但会恢复夜间配色缺陷；完整人员认可功能的回退边界仍见 [1.1.0 说明](1.1.0.md)，保留 0043 数据及约束。

最终部署结果记录到 #156，合并不代表已发布。
