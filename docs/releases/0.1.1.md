2026-09-09，用户确认并授权规划、发布 Issue 和实施。里程碑 `v0.1.1`；#30 打通材料上传与取用，#31 完成维护、预览和扩容，依赖 #30。

## 已确认行为

人物与组织拥有各自平铺的绑定材料列表。入口在现有动态栏右侧，带文件夹图标及有效材料数量；切换下方内容，保留顶部档案资料、动态浏览位置及未提交观察。共享界面同时用于原型和正式站，手机端保持操作可达。

支持选择或拖入多文件、下载、名称与一句说明维护、可恢复删除、恢复和彻底删除。上传者及管理员可维护；其他成员可读取有效材料。材料回收站及内容仅上传者和管理员可读，动态只保留通用操作及稳定 ID，不复制文件名或说明。档案关闭后只读，整张档案删除后仅管理员可只读核对，均不能维护材料。

人物默认 100MB，组织默认 200MB，1MB = 1,000,000 字节；只计算绑定材料，现有观察图片与头像规则不变。已删除材料仍计量，彻底清除当前对象后释放额度。准备上传时原子预留空间，过期、取消、失败可释放，进行中的预留须计入并发判断。管理员可调整单个档案的总额度，但不能低于类型默认值或已使用及有效预留；首版单文件上限 100MB。

常见静态图片及 PDF 支持鉴权预览，其他文件强制下载；文件不能作为应用同源活动网页执行。每份材料具有稳定引用入口，观察可引用，引用不豁免当前读取权限。上传、维护、删除、恢复、清除和扩容产生简短动态；查看文件元数据或上传成功不等于 Agent 已阅读内容。

网页与 MCP 调用同一业务层。MCP 支持准备上传、查询状态、列出、取用、维护和额度管理；本地文件由客户端按短期票据上传，票据不写入审计参数。暂不做多层目录、全文检索和自动解析，也不重新反复执行多轮真实 Agent 对话。

## 存储与费用

沿用私有 R2 标准存储和现有订阅。文件原文、回收站文件及元数据纳入现有备份与隔离恢复流程。彻底删除针对当前在线对象，既有私有备份沿用独立保留策略，不把存储实现与排错说明塞入主要界面。

按 2026-09-09 官方价，R2 标准存储每月含 10GB·月免费，超额 $0.015/GB·月，下载流量免费；操作费用及账户其他存储合并计算。用户接受约 10GB 材料规模，沿用此前每月 $10 云费用预算，未开通额外套餐。
