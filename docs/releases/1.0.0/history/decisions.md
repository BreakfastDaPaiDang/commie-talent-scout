## 已确认：多种联系方式提醒的对象与方式

提醒范围限定为：

1. 社员（组织内部成员，不等同于人事系统账号）。
2. 处于接触状态的组织。
3. 处于“外部社友”状态的外部人物。
4. “已加入待对接”的外部人物。

网页对上述对象提示补充多个联系方式；Agent 修改相关档案时，服务应在操作结果中返回同样的提醒，使 Agent 能继续提示用户。提醒不依赖 Agent 记住首次提示词，也不应将已经成功的修改报告为失败。

这是补充资料的提醒，不要求每张档案强制具备多种联系方式，不阻止保存。本轮不指定常态前端的具体提醒位置。

待 PRD 明确的细节：

- “接触状态的组织”如何对应现有“个人接触”“组织交流”等状态。
- “多个联系方式”的数量、去重与渠道口径，以及何时停止提醒。建议以少于两条不同的可用联系方式为起点，尚未定案。
- 哪些相关读取和修改结果携带提醒，避免重复催促。

## 已确认：新增外部人物状态“外部社友”

名称：**外部社友**。用户于 2026-09-28 确认，替代此前的“长期友好联系”“外部伙伴”等候选名称。

定义（用户确认原文）：

> 对方了解组织，并与组织、工作组或项目保持相对稳定的联系或协作，但不具有社员身份。

与“个人接触”的区别在于已建立组织层面的相对稳定关系，而不只是接触时间较长。工作组和项目具有一定独立性，参与其中不等于取得社员身份；这一关系可长期维持，不要求以入社为目标。

本轮确认名称与含义，具体状态规则留待 PRD 整理；尚未修改现有状态枚举或发布该功能。
