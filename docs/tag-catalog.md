# 人物与组织初始标签库

版本：v1，2026-09-08。依据用户提供的示例及已接受的整理原则形成；是可调整的初始词库，不是必须填满的评估表，也不描述任何真实人物或组织。产品规则见 [标签系统](./tag-system.md)。当前原型和 MCP 尚未实现标签功能。

人物 **34 个标签、7 类**；组织 **31 个标签、7 类**。两套词库独立，即使同名也不共用定义或绑定。首版允许继续创建类别与标签；初始项不享有特殊权限。

## 选词原则

- 一个标签表达一件事，描述写清适用范围。优先保留对查找能力、协作方式、可投入条件有直接帮助的特征。
- 有技能不等于愿意接任务，有资源不等于愿意提供，发展意向不等于已经具备能力；具体范围写入绑定依据。
- 没有标签表示尚未记录，不表示缺乏能力或不符合条件。可以只绑定两三个有用标签，不自动补全整张表。
- 阶段性特征的依据写明适用时间或任务；查看时能看到确认时间，不把过往状态永久化。
- 同类可多选。若本轮材料与既有绑定冲突，先检查旧依据，再修正绑定；新材料没有提及某项，不足以自动移除。

## 原人物示例的取舍

| 原示例组 | 处理与理由 |
| --- | --- |
| 视频剪辑、平面设计、文案、运营、办公软件、理论教学、网络安全 | 保留并改写为有范围、有依据的能力描述；工具品牌和专题写在依据，避免用“会某软件”代替交付能力。 |
| 日语 N3、外语交流 | 分离语言与翻译能力；证书、等级、方向和时间写在具体依据。 |
| KOL/小 V、高性能 PC、左圈人脉 | 整理为传播渠道、GPU 算力、专业联系；不从圈层或设备价格推出能力与使用意愿。 |
| 富哥、资产阶级、赚钱存粮 | 不作为首批词条。若确有可协作资源，记录具体资源与提供条件，不以财富或阶级概括人物。 |
| 数据考据、体感经验、工程方法 | 提炼为资料核验、数据论证、经验复盘、原型验证，只依据具体工作方法绑定。 |
| 语录教条、书斋哲学、抽象文化 | 不预置。用词风格不能直接推出能力、可靠性或政治身份，细节保留在观察中。 |
| 缺乏主见、偏爱独行、团队粘合、依赖、独立 | 拆成独立推进、明确步骤、同步/异步沟通、结对协作，避免把支持条件写成永久性格。 |
| 权力欲、理想奉献、喜欢被夸、焦虑、皮实、干就完了 | 不预置宽泛动机和人格判断；能被具体说明的协作偏好、方法和支持条件按现有类别记录。 |
| 高度抑郁、强迫症 | 移出词库；不从聊天诊断，也不作为自动排除成员条件。记录协作需要时使用本人表达的参与意愿、可用时间与所需支持。 |
| 秒回、失联 | 用具体回复约定或阶段性可用性描述；失联经过保留在观察，不自动改业务状态。 |
| 高中生、大学生、硕博、体制内、企业、自由职业/无业 | 不预置整套身份分类；需要时记录明确的经历，不从身份推定可用时间或能力。 |
| 考公、考研、留学、创业、程序员、设计师、自媒体、没有规划 | 保留明确的发展方向；备考或其他计划对投入的影响按本人说明记可用性，不从计划推断未来表现。 |
| 议题关注、政治主张、自我标记的意识形态 | 不作为首批默认分类。需要记录政治身份时仅依据本人明确自述，不由 Agent 从语言、交往或议题推断；议题关注也不等于个人性取向等身份。 |

初始词库不设“未知”“其他”“没有技能”“不可靠”等兜底标签；未知保留为空，确有重复使用价值的新特征再创建。标签用于资料理解与协作检索，不建立人物总分、自动录用/排除规则或政治定向说服画像。
