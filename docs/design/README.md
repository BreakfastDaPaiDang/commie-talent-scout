# 原型设计 · 第四版

日期：2026-09-08。当前以第四版原型为准；旧图和下方历史说明保留为过程资料，不以图中的虚构字段或权限为依据。

## 第四版：品牌、阅读与头像

新登录页使用独立生图插画：巨星建筑上的两人交接观察笔记。Logo 从星形与观察视线提炼成原生 SVG，应用于导航、登录和网站图标。登录页按用户纠正只保留一处品牌、两项输入和登录按钮，原型提示压成一句；不重复排列系统名、登录标题、说明、占位提示和页脚。[资产与提示词](./v4/README.md) 均已入库。

列表上部固定为名称、状态、负责人/关联成员，接着是观察摘要；底部始终显示未删除观察记录条数和更新时间。没有关联时写“关联 暂无”，不拿关联信息替换观察条数。

阅读字号整体提高：桌面观察正文 21px、摘要 19px；手机正文 19px、摘要 18px。状态和负责人至少 15px，表单主要文字 17–18px，字重及灰色对比同步调整。延续本地 Noto Sans SC；没有用更大的标题替代正文改善。

人物和猎头账号均可上传、更换和移除头像，优先级是有效上传图、QQ、默认形象；组织只有上传图或默认组织形象。头像更新传播到列表、详情、顶部账号、成员选择器、负责人和记录作者。个人入口改称“猎头账号”，管理入口改称“猎头管理”，权限模型仍为成员/管理员。

用户在本轮明确实测确认“上传头像没问题”。浏览器自动代选本机文件仍受到扩展限制，因此将用户手工验收与自动化证据分开记录；不声称服务端私有上传已完成。

本轮已检查 1920 桌面、1440 预览与 390 手机的真实页面，核对列表信息位置、正文实际 CSS 尺寸、猎头账号表单和简化登录；手机演示登录完成。构建通过。既有服务端验证没有在本轮重复执行。

## 第三版：让连续工作少一次中断

这轮把设计重点放在三个动作：找到自己正在负责的对象、回来接着写、从真正变化的地方继续读。原型已实现以下体验，正式持久化和服务端验收另由任务草稿落实。

- **找到对象**：紧凑索引顶栏，宽屏将标题、搜索、新建放在同一行；全部/我负责/有未读是常用范围，高级筛选按需展开。搜索覆盖名称、联系方式与未删除正文，旧观察命中时展示对应摘要并定位高亮。按 `/` 聚焦搜索，联系方式可点击复制。
- **回来继续**：按成员、页面记住查询条件；按成员、档案保留草稿和阅读位置。草稿随档案显示提示，切到另一份资料再返回可继续。内存预览刷新即清空，界面明确说明。
- **接着阅读**：未读页保留本次已阅条目位置；下一处未读定位到具体记录或事件，并能跨人物和组织。全部看完呈现观察员暂歇插画，阅读仍自动确认。
- **交给 Agent**：一段短使用说明和一个复制按钮。复制内容负责连接、临时/持久选择与核验，业务指导由 MCP 提供；当前原型没有正式 MCP 地址，复制内容如实说明。

排版更接近 Assembly：桌面约 1:2 的索引与阅读区，姓名和细描边状态横排，减少详情重复默认头像；顶部阶梯切角延续到观察输入框，轻虚线把资料区接到时间线。正文保留本地字体与 19 px / 手机 17 px 的阅读尺度。

本轮新增 [08 · Assembly refined](./round-08-assembly-refined.png) 与 [09 · Working notebook](./round-09-working-notebook.png) 两组生图探索，同名提示词可复用。08 用于精炼结构，09 用于研究更自由的节奏；最终没有采用生图里虚构的标签、口号或人像。

[第三版资产包](./v3/README.md) 包含实际用于界面的两张透明 PNG 和两件可编辑 SVG，并保存生成与修订提示词。PNG 是位图，不冒充矢量或分层源文件。

第三版浏览器检查覆盖 375、768、1024、1440 像素预览及桌面；已实际操作验证当前负责筛选、切页筛选记忆、旧观察定位、跨档案草稿恢复、阅读位置恢复、复制提示词及连续未读定位。下列第二版权限与头像检查为既有证据，未因第三版改样式而冒称重新完成云端验收。

## 延续的设计基础

现代构成主义，红、黑、白与中性灰。取消侧栏，改为紧凑顶部导航和列表/详情双栏。大字与留白建立层次，几何切角、细线和小面积红色贯穿界面；趣味集中于默认头像与登录构图。

字体为本地托管的 Noto Sans SC 可变字体（界面名 CTS Sans），附 [OFL 许可证](../../prototypes/frontend/public/fonts/OFL.txt)，来源为 [Google Fonts 字体文件](https://github.com/google/fonts/tree/main/ofl/notosanssc)。第四版实际字号以上方说明为准；名称、正文、作者、时间与系统事件各有明确级别。中文正文不使用艺术字体。字体不请求外部 CDN；当前原型包含完整字符集，正式交付可做分片加载。

人物默认形象是戴帽、拿望远镜的“观察员”；组织是长着眼睛、有门与旗帜的“小会所”。二者从本轮角色探索提炼成独立 SVG，能在小尺寸下识别；不使用姓名首字。页面内容区使用平直网格，登录页允许更自由的斜面和组合。

## 业务信息的排布

- 档案只保留名称、联系方式等有效资料，移除别名和简介。状态与绑定分开显示，只展示当前状态的成员。
- 人物三个工作状态（引荐中、人事审核、已加入待对接）显示“人事负责”；组织“组织交流”显示“工作负责”，以小红菱形标出工作事项。工作状态必须至少绑定一人；其他状态可选“关联成员”。
- 成员采用搜索下拉多选，可按名称或账号搜索；当前十六名虚构成员，一名冻结。靠近弹窗底部时向上展开，候选列表独立滚动；键盘方向键/Enter/Escape 可用。
- 时间线以观察正文为主，操作事件降低视觉重量。记录编辑保留正文与图片版本；已删除页只展示原作者/管理员有权阅读的记录。
- 未读没有手工操作。详情内对应记录或事件的起始内容在前台进入视口后，650 ms 防抖自动确认；列表摘要不触发。事件 ID/版本与成员各自保存，后台与弹窗期间暂停。
- 桌面详情可展开阅读；手机显示列表或详情单页，顶部仍保留人物/组织/未读。账号与 Agent 工具收进菜单。

## 头像行为

人物和猎头账号优先使用有效上传图片，未上传、移除或加载失败时才尝试 QQ；人物取联系方式中的第一条有效 QQ。组织即使填写 QQ 也不转用 QQ 头像。所有来源不可用时回到对应默认角色。人物与账号不因 QQ 相同自动关联。

正式实现采用按档案/成员标识鉴权的私有头像访问：24 小时新鲜期，过期访问刷新，失败保留旧缓存，首次失败回退默认形象。更换 QQ 不沿用旧来源图片；缓存刷新不产生活动排序或未读。关闭档案、冻结成员暂停刷新。

参考用户提供的 [makeshift-dev 头像路由](https://github.com/mmm8091/makeshift-dev/blob/5724b917d200b2e1ae6051a52267ba5565dd9d03/app/api/avatar/qq/%5Bqq%5D/route.ts)的固定上游与缓存思路。本机原型 Vite 帮助路由只接受 5–12 位数字、限制返回类型/大小/耗时并最多缓存 100 项；它没有生产鉴权，不可直接部署为正式头像 API。正式方案仍需持久缓存、关闭/冻结策略和云端验收。

## 第二版验收记录（保留）

运行说明见 [前端原型](../../prototypes/frontend/README.md)。在实际 Chrome 中查看桌面 1920 × 912、390 × 844 手机预览，并操作验证：

- 工作状态未指定成员拒绝保存；搜索选择多名成员后，当前负责人替换正确，旧关联在历史中保留。
- 管理员可见两条已删除记录；普通成员沈舟看不到他人的删除正文；原作者何其可见自己的已删除正文、历史及受限虚构图片。
- 手机长状态、成员搜索下拉与弹窗层次；修复靠近弹窗底部的下拉截断。
- 长文自动阅读：另一成员看过上方长记录后，下方未显示记录仍为未读；滚动到下方记录后自动移出未读列表。无手动已读操作。
- 非工作状态不选成员可创建；虚构 QQ `00000` 的头像在浏览器实际加载成功。帮助路由非法参数返回 400，虚构号返回 JPEG；不代表真实账号头像来源已做身份校验。
- 组织“组织交流”清空成员后拒绝保存；组织头像不会因为联系方式含 QQ 而自动替换。
- 图文编辑时展开/收起预览保留未保存正文，保存后历史同时显示新旧版本与图片。
- 登录页完成演示账号登录；桌面与手机使用同一套角色、字号层次和控件。

服务端删除读取权限另有 [本地 16 项套件证据](../validation/local-v1.2-deleted-visibility.json)，包括 HTTP/MCP/旧图片地址限制。旧云端测试不覆盖 v1.2 新权限，不能混作已验收。

## 电脑端 UI 打磨（2026-09-08）

用户确认现有设计方向，要求优先保证电脑端体验。本轮不调整产品规则或 MCP 方案。

- 详情内容区最大宽度调整为 1040px，正文保持 21px；列表收紧上下及信息组间距，保留摘要字号。展开阅读使用相同内容宽度并居中。
- 观察输入框展开前后统一为 20px。详情操作、记录历史按钮扩大鼠标点击区域，历史入口提高对比度；输入、搜索及键盘焦点采用清晰的红色反馈。
- 电脑端长表单保留底部保存/取消操作；错误提示显示在弹窗标题下方，与成功提示区分，重复提交会重新显示。关闭弹窗清除错误，保存成功提示仍保留。
- 弹窗具有可访问名称，打开后聚焦输入项，关闭后焦点返回原入口。只在按下和释放均位于遮罩时关闭，避免内部空白或拖选释放造成误关闭。
- 动态标签支持左右方向键、Home/End；只有当前标签进入 Tab 顺序，并与内容面板关联。

浏览器检查覆盖 1920px 桌面、1440px 电脑布局无横向溢出、表单自动聚焦与 Escape 返回、动态标签方向键/Home/End、缺少负责成员及无效 QQ 的弹窗内报错、底部操作可见、创建后成功反馈。构建通过。窄屏布局沿用第四版，本轮未做新一轮手机适配；遮罩边界行为经代码检查，未自动模拟拖选。
