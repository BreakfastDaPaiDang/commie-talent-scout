# 桌面任务工作台 · 当前重构

本轮重构先处理电脑端，不扩展手机端布局。任务页从普通卡片列表改为“任务索引 + 当前工作场景”的双栏工作区，服务于快速发现下一步动作，再进入关联档案沉淀结果。

## 页面层级

任务页的第一焦点是当前动作，不是任务类型或完整说明。单项任务按以下顺序组织：

1. 当前要做的动作；
2. 关联人物或组织；
3. 当前责任与期限；
4. 一句工作目的；
5. 交付要求、操作历史和完整过程（按需展开）。

左侧索引按注意力分组：现在需要处理、等待接手、其他进行中。任务类型保留为小型识别信息，不决定页面结构。右侧固定为当前任务场景，切换任务时保持容器稳定，只移动焦点内容。

档案是任务的工作上下文。打开关联档案时通过任务参数保留返回位置，返回任务页后恢复原任务焦点；不在任务页复制完整档案内容。

## 视觉和动效

红色表示当前焦点、主要动作或临近期限；黑色承担标题和结构；灰色承担辅助信息。任务索引使用红色侧标表达选中，右侧场景使用切角和短距离进入动画表达焦点变化。领取、交还和完成沿任务所在分组的变化表达责任转移，不依赖装饰性庆祝动画。

悬停人物速览保留为辅助表达，不作为页面结构前提。它只能提供对象确认、当前状态、最近观察和进入档案入口，不能替代任务场景或档案详情。

## 当前范围

本轮只覆盖桌面任务页、任务与档案之间的返回上下文，以及现有任务操作的视觉承载。手机端布局、已结束任务的独立历史分组和更复杂的悬停转场另行设计。
