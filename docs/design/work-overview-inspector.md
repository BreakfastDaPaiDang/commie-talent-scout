# 工作总览侧栏减法（#118）

用户反馈：本段落实大弹窗与主表脱节、横纵双滚动、信息重复、侧栏功能过多。此次调整仍在 feat/work-overview-v2，不合入 main。

## 实际参照

- [Linear 官方 Custom Views / View sidebars](https://linear.app/docs/custom-views#view-sidebars)：核对官方视图侧栏截图，采用紧凑标题、平整分组、细分隔线和弱化的辅助信息。
- [Linear 官方 Issues / Editing issues](https://linear.app/docs/creating-issues)：正文原地编辑。
- 核对了官方截图，未登录私人 Linear 工作区，也没有声称完成 Linear 实际账号操作。借用其层级和交互原则，保留本项目红白配色与原有组件。

## 对应到本项目

| 原界面 | 本轮处理 |
|---|---|
| 重复整条阶段导航、时长、日期、资源摘要 | 删除；顶部只留对象和紧凑经历选择，以定位窄短的历史段 |
| 需求、任务、观察编辑表单同时铺开 | 默认只有详细观察；新增观察按需展开，需求/任务收在相关工作 |
| 本段落实居中大弹窗与遮罩 | 同一侧栏切换编辑模式，一次只处理当前编辑 |
| 展开即列全部资源 | 可选折叠资源选择，支持搜索；主操作只有保存落实 |
| 侧栏与图中位置关联弱 | 主表选中段保留经历类型颜色并增加轻量底边强调 |

原地编辑未改变业务字段、权限或保存接口。说明与关联资源均可为空，计划使用/已落实仍分别保存；历史已删除资源保留原引用且可移除。保存期间禁用阶段切换与关闭，失败保留输入，不确定结果以相同请求重试。

## 验证

使用隔离 SQLite 与真实 HTTP Worker，1440×1080 和390×844：默认无重复阶段条/天数、没有展开的观察表单；编辑落实不打开 dialog；资源搜索、计划/落实切换、空资源保存、取消不保存、保存后重开读回、已删除资源历史引用可查看。完整手机编辑无横向溢出。
