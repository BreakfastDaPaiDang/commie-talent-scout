# 知识库工作台

2026-11-13 用户确认并要求实施。本文是 #145 本轮知识库界面、协作及数据行为的需求正文；此前的生产资源目录草稿不再决定知识库导航和共识流程。

## 范围

普通页默认进入「全部」，依次展示我的草稿、待认可和已入库文档。成员可以随时返回同一组继续阅读或讨论已经投过票的候选，也可以切换到「已入库」专门查阅正式文档。点击候选可阅读此次提交的正文或修改、票数与剩余时间。已入库收录当前生效的文档。已有文档或候选的分享链接直接打开对应内容。

需要查看分支、议题、合并记录时可打开「版本协作」。议题用于讨论，文档版本与标签提议各自接受认可。

用搜索和「标签筛选」查找文档。筛选器支持按名称、词义查找，也可以查看与维护已有标签。写文档时可以就地提议新标签并选用，待认可标签用虚线表示。标签与文档各有七天的认可期，各自获得三名不同正式成员认可后生效。文档可以先入库。Agent 读取文档时只能看到已生效的标签。标签改名或修改解释同样经过认可，期间沿用原词义，通过后保留原有文档关联及批注来源。

文末的「评论与历史」沿用任务时间线，按当前文档或候选版本呈现评论、回复和可以追溯到这篇文档的记录。成员在已入库文档下也能阅读和回复该文档已采纳版本的公开讨论。批注以具体版本、原文及字符范围定位：拖选／长按选择文字，点击浮出的“批注”，在原句下输入并发布，发布后直接显示在句下。原文变更后，仅在能唯一确定原句时继续定位；否则保留原引用并归入旧版本批注，不错误附着到其他句子。两种模式共用评论数据。

批注常态仅显示 40% 不透明度深灰底、头像和楷体文字，不常驻姓名、时间、计数或操作栏。选中引用范围或对应批注时，原文加粗；点击别处或 Esc 清除选择，滚动保留选择。批注右键或键盘菜单可回复，编辑时才出现发布与取消按钮，支持 Ctrl/Command+Enter。只读接收者也可选中定位，但不请求成员人事头像。

文档与标签解释的批注均可通过右键、长按或键盘菜单“发起议题”。提交页保留原引用、标题及批注内容，可编辑议题标题与讨论内容。议题保存来源快照，后续改写标签解释不会改写议题依据；私人来源须先公开才可进入成员议题。

知识库右上角的问号打开“知识库使用教程”，手机列表与正文均可访问。教程按当前页面优先展开按钮说明，支持搜索按钮或操作，收录现有的提交、同意、并存选择及删除规则；不另设自动通过条件。关闭教程不改变当前文档、范围和分支，也不执行保存或发布。接收者仅获得适用于阅读的教程。

## 共识与权限

正式成员可以创建分支、修改、提出议题、评论及表达同意。糖果授权接收者可以阅读主分支、已发布历史、文档评论和已认可的相关标签。旧私人草稿由原作者本人访问。

各篇文档从提交审核起各有七天投票期。同一版本收到三名不同正式成员明确同意后取得合入资格，截止后仍可处理冲突或候选选择。截止时未达标的候选停止收票，原私人草稿回到草稿列表，可重新提交。重提和修订各开新一轮投票，之前的票保留在原版本。升级时仍开放的旧审核从迁移时开始计算七天并保留既有同意。

从草稿底部的「提交到审核」核对并公开单篇快照。同分支的其他篇目、历史和批注继续留在源草稿。重复提交同一版本会返回已有的有效审核。收到第三票时，如果这篇文档与主分支无冲突且没有同篇的其他有效候选，系统同时保存本票并合入文档。

同一篇文档的多个达标候选并存。明确执行合入时，通过会议记录或已有选择结论的议题选定本次合入的版本。议题结论与同篇达标候选的版本集合绑定。其他候选、分支和同意历史继续保留。议题关闭与合入分别操作。

分支创建者可以在分支页删除自己的非主分支，确认后退出列表并返回主分支。删除同步关闭该分支尚未完成的审核，保留已合入内容、版本、批注和同意记录；原私人草稿仍在时，删除候审分支会让它重新进入草稿列表并允许再次提交。删除私人源分支不撤销已经单独公开的候审快照。服务端核验当前正式成员、创建者身份和分支版本，主分支始终不能删除。

主分支为只读共识。「建议修改」和「新文档」先保存私人草稿，再由底部入口提交审核。版本协作也按文档发起合并请求。旧批量候选保留原有审核记录，由作者逐篇重新提交新增、修改或移除。合入前校验与主分支的共同基础，发生冲突时先在分支解决并重新征求同意。

## 数据与交付

知识库数据、分支、评论、议题、同意和历史仍在独立 Cloudflare D1；主站只核验身份并代理服务。已有资源权威迁移及糖果授权边界保留，培养实训、人员审核制度和完整宪法不在本轮范围。网页与 MCP 使用同一服务规则。

验收包含独立数据库、身份隔离、三人门槛、多候选并存、改稿后重新同意、冲突处理、重试幂等、标签空项、批注定位和隐私；桌面及手机完整编辑、评论、合并表单和真实接口均单独验证。部署与业务任务交付确认分开，自动发布不自动关闭 #145。

## 2026-11-16 前端纠偏（#161）

一篇文档可以选择多个标签，任一标签都能找到该文档。各版本保留当时的标签关联，旧文档沿用原有标签。知识标签用于平铺筛选，不作为目录；文档直接列在同一列表。再次点击当前标签可取消筛选，切换标签清除旧文档选择，避免详情保留另一个筛选范围的内容。详情以标签展示关联，不使用“标签 / 类型”面包屑。新建和修改文档仅选择标签、填写标题与正文，不再要求维护条目类型；已有类型字段保持兼容。编辑、标签解释与留言、批注来源、手机返回入口和按钮说明使用相同术语。
