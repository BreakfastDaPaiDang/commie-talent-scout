# 知识库工作台

2026-11-13 用户确认并要求实施。本文是 #145 本轮知识库界面、协作及数据行为的需求正文；此前的生产资源目录草稿不再决定知识库导航和共识流程。

## 范围

知识库沿用主站黑色顶栏、白色列表和正文双栏、同款无光泽红色按钮。共享组件位于 app/ui，正式接口和原型使用同一组件。简与繁是同一数据的两种操作视图，不另建一套页面。

简模式默认阅读主分支。简、繁均提供“主要／公开／草稿”：主要对应 main 的现行已通过内容，公开展示面向正式成员的候审版本，草稿展示本人的私人未提交内容。繁模式在左侧标题、搜索之下提供紧凑的分支选择器，主分支统一显示“主分支”；删除展开操作、正文上方面包屑和空白页重复的议题入口。内容、议题、分支和历史分别承载阅读、独立问题讨论、分支图及合并、版本记录。分支图只出现在分支页，标记当前分支和真实提交关系。

分类可以自建，技术、知性、组织、工程不是固定枚举。分类旁红色加号只打开名称与解释表单，不再要求同时创建文档。独立创建的分类允许暂时为空；旧的随文档产生的分类在所选分支没有文档时仍退出导航，搜索无结果不删除分类。右键、手机长按或键盘菜单键打开窄浮层，默认收起。可在浮层中编辑名称和解释；改名保持分类身份及文档关联，解释支持圈选批注并保存历史引用。

文末提供普通文档评论。批注以具体版本、原文及字符范围定位：拖选／长按选择文字，点击浮出的“批注”，在原句下输入并发布，发布后直接显示在句下。原文变更后，仅在能唯一确定原句时继续定位；否则保留原引用并归入旧版本批注，不错误附着到其他句子。两种模式共用评论数据。

批注常态仅显示 40% 不透明度深灰底、头像和楷体文字，不常驻姓名、时间、计数或操作栏。选中引用范围或对应批注时，原文加粗；点击别处或 Esc 清除选择，滚动保留选择。批注右键或键盘菜单可回复，编辑时才出现发布与取消按钮，支持 Ctrl/Command+Enter。只读接收者也可选中定位，但不请求成员人事头像。

文档与分类解释的批注均可通过右键、长按或键盘菜单“发起议题”。提交页保留原引用、标题及批注内容，可编辑议题标题与讨论内容。议题保存来源快照，后续改写分类解释不会改写议题依据；私人来源须先公开才可进入成员议题。

知识库右上角的问号打开“知识库使用教程”，手机列表与正文均可访问。教程按当前页面优先展开按钮说明，支持搜索按钮或操作，收录现有的提交、同意、并存选择及删除规则；不另设自动通过条件。关闭教程不改变当前文档、范围和分支，也不执行保存或发布。接收者仅获得适用于阅读的教程。

## 共识与权限

正式成员可以创建分支、修改、提出议题、评论及表达同意。糖果授权接收者只读主分支及其已发布历史、文档评论和分类定义；成员议题与合入前中间稿不对其开放，也不获得主站人事档案权限。旧私人草稿保留原作者的私密范围，不自动公开。

用户确认：三名及以上不同正式成员同意后才具备合入资格。同意绑定具体分支提交；内容修改后须对新提交重新同意，不继承旧票，不自动给作者投票。不沿用七天到期。

草稿正文区域底部固定整行同款红色“提交到审核”按钮。提交页核对当前单篇内容，确认后只将这一篇快照推进公开候审，不公开同一私人分支的其他篇目、历史或批注。同一快照重复提交返回原审核。公开候审提供“点赞同意”；第三名不同正式成员点赞且没有冲突、并行候选或其他待选择的达标候选时，原子地进入主要库。存在并行替代方案时保留候审并提供“查看审核”，多个达标候选沿用议题或会议选择。

达到门槛不按先后自动淘汰其他候选。明确执行合入时，若有多个达标候选，保留并存，主分支保持原状，必须记录会议结论或已形成选择结论的议题再选定合入。未选中的分支及同意历史保留。管理员没有绕过三人门槛的通道。会议结论由操作者如实记录，系统不宣称自动验证线下会议。议题关闭与代码内容合入是两个动作。

分支创建者可以在分支页删除自己的非主分支，确认后退出列表并返回主分支。删除同步关闭该分支尚未完成的审核，保留已合入内容、版本、批注和同意记录；原私人草稿仍在时，删除候审分支会让它重新进入草稿列表并允许再次提交。删除私人源分支不撤销已经单独公开的候审快照。服务端核验当前正式成员、创建者身份和分支版本，主分支始终不能删除。

主分支不能直接编辑。“建议修改”和“新条目”先保存私人草稿，再由底部入口提交审核。旧的整分支合并请求仍使用显式合入操作。合并校验与主分支的共同基础，发生冲突时先在分支明确解决并重新征求同意，不静默覆盖。

## 数据与交付

知识库数据、分支、评论、议题、同意和历史仍在独立 Cloudflare D1；主站只核验身份并代理服务。已有资源权威迁移及糖果授权边界保留，培养实训、人员审核制度和完整宪法不在本轮范围。网页与 MCP 使用同一服务规则。

验收包含独立数据库、身份隔离、三人门槛、多候选并存、改稿后重新同意、冲突处理、重试幂等、分类空项、批注定位和隐私；桌面及手机完整编辑、评论、合并表单和真实接口均单独验证。部署与业务任务交付确认分开，自动发布不自动关闭 #145。
