# 0008 — 任务审阅的事实、关联与到期汇总

日期：2026-09-09。状态：已采纳。对应 Issue #12。

服务只知道实际收到的请求及自身提交结果。任务原话、Agent 转述和自报模型分别保存并标记来源；缺失时保持未知，不从凭证、时间或客户端名称推断任务或模型。任务关联 ID 不授予权限，也不同于单次尝试或业务幂等请求 ID。

调用适配器提供有界结果摘要；另存严格白名单的 ID、版本、标志与完成批次作为 180 天元信息。任务详情由明确关联调用的产物标识读取当前业务投影，来源副本在当前权限及来源可用性下展示。管理员可读已删除观察，降权后不能继续从审阅接口读取。缺失任一来源时，可能混合引用的副本整体隐藏，列表目的和搜索也遵守该限制。

30 天后清理参数、任务文本、来源副本及自报模型；读取时同样执行到期限制，不依赖定时器准时运行。180 天后先按 UTC 日、工具和执行结果累加匿名计数，再删除元信息，使用同一 D1 事务保证失败可回滚、重试不重复。汇总不保存成员、凭证、任务、产物 ID 或任何正文。观察、历史和附件按各自业务生命周期保留。

已知业务重放不重复计为新产物；尝试次数仍保留。调用采集失败不会把成功业务改报失败，因此统计必须披露缺失风险。任务数、调用数、标签复用和后续变更用于人工判断，不生成质量评分。过期汇总只有整日精度，不伪造任务数量的工具归属或精确时间分布。
