# 整张档案可恢复删除，冻结账号默认退出管理列表

日期：2026-09-09。状态：采纳。关联：GitHub #20、#21。

已弃用表示业务结束，用户仍需要把误建或验收档案移出常规工作区。档案增加独立的可恢复删除状态，仅管理员可以删除、查看回收列表和恢复。开启、关闭档案均可删除；删除不改变业务状态，也不删除观察、版本、图片、成员归属或标签绑定。恢复保持原状态，已单独删除的观察仍保持删除。

普通列表、搜索、范围统计、未读、草稿列表和标签维护影响范围都排除已删除档案。其他成员即使是观察原作者，也不能通过观察详情、历史版本、附件或头像旧地址读取档案内容。管理员可以直接只读核对回收内容；恢复前不能修改资料、观察、头像、标签或草稿，也不能重新开启。Agent 新任务不能关联已删除档案；旧任务副本与产物在普通任务审阅中隐藏，恢复后按原有期限与权限读取。

开启档案删除时冻结标签词义，关闭档案沿用关闭快照；不改变底层绑定与依据。恢复开启档案采用当前词库定义，关闭档案继续采用原关闭快照。公共标签维护不迁移回收档案的绑定。删除与恢复都会使旧影响范围预览失效。

HTTP 与 MCP 共用档案命令，以管理员权限、档案版本、删除状态及请求收据在同一事务内提交，写入独立删除/恢复事件。删除状态变化撤销旧阅读票据，恢复不能让旧票据复活。历史已读标记仍保留。

猎头账号沿用已有冻结机制：禁止登录并使旧凭证失效，保留原始作者身份和历史归属。猎头管理默认仅列出可用账号；已冻结范围供管理员查看及解冻，显式全部查询可用于管理核对。筛选发生在分页之前。档案中的既有冻结成员仍显示冻结标记。

共用界面的新增区域为编辑窗里的删除入口、关闭档案提示条、删除确认窗、管理员已删除档案列表及账号范围切换。继续使用 `app/ui/` 的列表、详情、弹窗与页签，不另外维护一套页面。
