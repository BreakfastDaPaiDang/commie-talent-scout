# QCE 辅助导出由本机 Agent 执行，MCP 提供指南

日期：2026-09-10。状态：采纳。关联：Issue #37。

成员需要把 QQ 聊天导出后交给 AI 整理，不需要网站导入功能。辅助工具页使用共享界面，首项推荐 QQ Chat Exporter 的 Windows Framework 包，下载链接指向 GitHub 最新 Releases 页面。教程说明固定文件夹完整解压、退出 QQ 和旧后台、通过 `napiLoader.bat` 同时启动 QQ 与工具后台、登录和导出 TXT。

沿用 ADR 0003 的云端 Worker MCP。`get_usage_guide(topic="qq_export")` 提供本机操作方法，MCP 入口、概览与主题目录提供发现路径。成员电脑上的 Agent 使用自身文件、进程和 HTTP 能力执行；云端不连接成员 localhost、不代理 QCE、不接收本地 QCE 令牌，也不新增一个声称能远程启动/导出的空工具。

指南区分无本机能力、程序未定位、确认未安装、未启动、未登录、已在线与导出任务状态。便携解压目录未知时询问位置；会中断桌面 QQ 的操作需先说明并获得授权。服务身份、端口监听、QQ 在线和任务完成分别核实，不能用页面 HTTP 200 代替可导出状态。

接口参考固定到已核对的 QCE v6.2.10 源码，执行时核实实际版本。使用本机令牌和已确认的 loopback origin，按会话与时间范围创建导出任务；响应丢失先查询任务，完成后核验本次文件。读取并整理导出内容不等于允许上传原始聊天或提交档案，继续沿用现有草稿与确认规则。

这次交付是推荐页和操作指南，不承诺上游未来版本的接口兼容，也不把指南验收等同于对所有成员 QQ 历史记录的完整性保证。
