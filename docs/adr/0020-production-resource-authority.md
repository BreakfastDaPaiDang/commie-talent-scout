# 生产资源库成为资源唯一权威来源

维护者于 2026-11-12 将独立服务范围确认为发布岗位与资源、负责人点对点接收，以及通过库内 issue 修订；实训和验收暂缓。新库是资源唯一权威来源，既有主站资源须保留 ID 与历史迁移，主站业务通过服务接口引用，不能继续独立写入旧资源目录。保留独立 D1/Worker/发布与主站身份核验，正式成员维护，糖果访问授权仅提供本库阅读能力。

此决定替代 ADR 0019 中以文章认可机制定义全部服务的业务边界。旧文章及其历史保留为参考，三人七天和正式社员投票规则不适用于新业务。普通信息变更采用与目标版本绑定的 issue，由记录维护者处理并保留依据、结果和版本历史；实际生产决策与系统记录维护分别表达。

跨服务迁移采用写入冻结、完整复制与核对、权威来源切换的顺序，失败时不能静默回退为两套可写资源。主站现有人物、观察及人事任务继续由主站拥有，糖果接收不自动推进这些流程。
