# 标签定义与绑定依据分离，保留历史词义和来源权限

标签是会被共同修改的词汇，绑定是针对具体档案的判断，因此分别保存定义版本、绑定及来源依据；开启档案采用当前定义，关闭档案和历史保留当时词义。直接把标签字符串和依据摘要复制进档案虽然简单，却会让公共改名重写关闭历史，并让已删除观察的内容通过标签泄露；派生绑定因此沿用其来源的读取权限，独立依据分别处理。此决定延续观察删除和关闭锁定规则，具体产品默认值见 [标签系统](../tag-system.md)。

2026-09-09：公共维护、迁移及停用共用成员身份约束的预览。预览记录定义版本与影响集合修订，数据库触发器在绑定、来源可见性、关闭状态或相关定义变化时推进修订；提交事务内再次守卫，不依据客户端带来的计数执行。预览一小时到期，已提交请求仍可从幂等收据重试。

词义迁移与同义合并每批最多 10 个明确选择的开启档案，整批原子提交；跨批结果明确列出完成、未选开启及关闭保留项。含义改变需要逐档案新依据；合并保留目标重点并去重依据，原添加者可从绑定与历史追溯。恢复已合并词条清除当前跳转但不把已迁出绑定自动迁回，旧合并历史保持。

筛选按当前词库类别分组、稳定标签 ID 匹配；关闭档案读取冻结绑定，当前来源权限先于命中、计数和分页。类别颜色继续使用当前显示设置，其余关闭词义不随公共维护变化。
