# 档案绑定材料与原子容量预留

2026-09-09，采纳，关联 #30、#31 与 [0.1.1 范围](../releases/0.1.1.md)。

材料独立于观察图片与头像，拥有不可变文件内容、可修改名称/说明、上传者、档案归属及可恢复删除状态。R2 沿用私有桶，用独立前缀区分材料，D1 新表保存状态和引用；不放宽图片服务的类型和历史引用约束。

档案额度使用独立版本，与档案关闭/删除事务边界共同约束材料修改。准备上传时在同一 D1 batch 内复核身份、档案可写、有效预留和已用量后预留；完成上传时再次核对身份、档案及上传租约。客户端申报的字节数与 SHA-256 固定，R2 校验内容哈希，只有实际大小匹配的完整对象可进入材料列表。

R2 与 D1 无共同事务。上传完成但元数据失败的对象仍作为暂存对象回收；彻底删除先以幂等命令把材料转入不可读取/恢复的清理状态，清除 R2 对象成功后才能标记已清除并释放在线额度。清理失败由后续请求或定时任务重试，不能提前释放容量或把对象恢复成可读。文件名、说明和原文不复制到普通动态，回收权限由材料读取端强制执行。

材料读取始终通过当前成员鉴权，预览响应约束内容执行，普通文件强制下载。Agent 取用地址使用当前认证，不产生绕过账号撤销和档案权限的永久公开链接。稳定的档案/材料引用允许在观察中引用，删除和权限变化立即作用于后续打开。

备份扩展现有内容寻址对象清单，恢复核对大小和哈希。迁移只新增表和默认列，保留旧服务兼容性；已发布 0.1.0 tag 不改写。

PDF 预览采用本地 PDF.js 按需加载、逐页画布渲染；不启用文档动作或 HTML 注释层，不依赖浏览器内嵌 PDF 插件。所需字库、CMap、ICC、WASM、Worker 和许可证一同发布。页面尺寸限制渲染像素量，关闭时终止任务并释放 Blob。
