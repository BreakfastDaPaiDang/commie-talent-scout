# 人物档案与本人账号（#86）

2026-10-12：用户要求首批社员录入时，已有猎头账号者的昵称绑定账号。

- `archives.linked_account_id` 表示档案所描述之人的账号，不是维护档案的关联成员，也不赋予任何权限。一个账号至多对应一个人物档案，包含已删除档案，避免删除后重复建档。
- 管理员根据明确身份依据（本批使用精确 QQ）绑定真人账号；首次绑定限社员，之后退出或转社友仍保持同一身份。账号冻结不解绑，不为未建号者创建登录账号。
- 绑定后昵称由账号维护。账号资料命令的历史事件在同一事务同步档案昵称、版本和资料变化历史；账号或档案写入失败一起回滚。完整编辑表单显示只读昵称，其余字段照常维护。
- 这种全局身份名称变更同样反映到关闭、删除档案的当前标题；旧历史载荷保持原名。同步不修改档案实际联系更新时间，不通过账号改名延后接触提醒。账号 QQ 变化不换绑，也不覆盖档案联系方式。
- 导入前按 QQ 核对全部现有、关闭与删除档案。名单原称呼若与账号昵称不同，保留在 QQ 备注供检索；不制造观察、入社日期或自动任务。后续主用户系统 ID 可另加身份来源，不以 QQ 作为长期外键。
