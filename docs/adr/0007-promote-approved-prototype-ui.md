# ADR 0007：已确认原型直接成为共用界面

- 状态：采纳
- 日期：2026-09-09
- 依据：用户要求在最后确认的原型代码上继续正式化，不再另写页面后补样式。

原正式页面另建 archive-*、observation-* 等结构，虽然复制了原型 CSS，许多选择器不再命中。后续 assembly.css 局部覆盖又形成两套尺寸和断点，遗漏了独立滚动、展开阅读、键盘切换、成员下拉和弹窗焦点等交互。此前只检查少数节点存在，不能检出完整布局偏移。

将 `531ab51` 原型的基础样式和界面结构迁入 `app/ui/`。原型和正式站直接使用同一套组件；前者保留虚构内存数据适配，后者保留已有服务命令、权限、版本、幂等、草稿、图片和阅读回执。移除正式站重写的布局 CSS 和 assembly.css，不回滚后端或真实数据。

新增标签、连续动态分组等已批准的功能在明确区域接入，不改变已有基础界面规则。冻结的历史提交作为对照来源，并在无界面浏览器中比较历史原型、当前原型和正式页面。通过真实 staging 的读写操作验证适配器，布局与协议均有独立证据。

这增加了原型与正式站在 UI 模块上的有意依赖：一次界面改动会同时作用于两者。数据模型与后端保持分离，原型虚构数据不能进入正式构建。
