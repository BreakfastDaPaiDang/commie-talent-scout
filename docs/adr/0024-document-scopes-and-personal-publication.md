# 多选文档范围与个人公开发布

2026-11-22 确定文档范围随版本保存。范围用于选择默认阅读内容，也决定提交时是否需要共同认可。此前 ADR 0023 以知识标签试验了多范围去重。现在把工作范围设为独立字段，原来的标签继续描述文章主题和形式。

第一批范围为「全组织通用」「人事组内」「个人：社员名」。个人归属由系统按账号当前绑定的社员档案填写。已发布的文档均可由知识库读者查阅。普通「保存草稿」仍留在草稿区，作者明确发布后才进入生效库。

| 提交的版本 | 生效方式 |
| --- | --- |
| 本人新建或修订仅属于本人的个人文档 | 本人发布即生效 |
| 新增、修改任何包含共享范围的文档 | 逐篇按七天、三名不同社员认可的既有规则审议 |
| 已生效的共享文档改为仅个人 | 范围变更也须认可，候审时仍使用原版 |

人事 MCP 默认读全组织通用、人事组内以及当前绑定社员的个人文档。账号可以增加默认范围，主站和独立知识 MCP 共用这项设置。两个设备或客户端使用同一账号，会得到同一份阅读设置。临时查阅别人的公开文档可以直接检索。一次查询先选中匹配任一范围的文档，再分页，因此同时选了三个范围的文档也只有一份。

原知识库用于人事工作。缺少范围的旧版本按「人事组内」读取，使原有审核依据继续随人事会话加载。既有待认可票数和草稿保存状态沿用原记录。
