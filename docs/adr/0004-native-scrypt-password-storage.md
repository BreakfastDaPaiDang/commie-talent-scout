# 使用原生 scrypt 存储密码

PBKDF2-SHA256 600,000 次在真实 Workers 环境超出运行时限制，因此选择已实测可运行、对应 OWASP 参数组合的原生 scrypt，而不降低 PBKDF2 迭代强度。

当前参数为 N=32768、r=8、p=3，密码记录携带算法版本与参数；云端探针 CPU 为 402 ms，正式部署需确认 Paid 档位并实现限速和 KDF 并发约束。

成员创建/重置的幂等收据不把临时密码纳入快速参数摘要。收据使用该命令生成的带盐 scrypt 哈希核对重试密码，保留相同成本，避免额外的 SHA-256 密码猜测入口。密码与哈希均不进入业务结果、管理历史或 MCP 请求留存；重试比较同样受密码计算限速约束。认证 epoch 的推进与管理事件、业务修改和收据在同一 D1 事务提交。
