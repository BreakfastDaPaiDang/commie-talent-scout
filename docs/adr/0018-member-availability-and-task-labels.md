# 社员可参与情况与独立任务标签

2026-10-13，用户确认，Issue #96。

社员基本状态为可接工作、暂不接工作、请假、失联，由人事按实际反馈维护。取消未来根据未过期任务自动推导“工作中”的方案；关联任务表示工作情况，不能从有任务推断无法接活。项目冲刺等短期原因留在观察，不扩展为状态。四种状态均持续生成月度跟进。

月度跟进关注近期活动与进展、本人想法与参与意愿、支持需求及后续约定，不要求逐项问完。MCP 的档案、工作任务、材料整理指南共用社员说明。当前需求、状态与标签分开建议；外部人物仍按接触与审核流程维护。

任务标签是独立共享词库，与档案标签分开。网页与 MCP 使用同一搜索/新建服务；名称去空白、同名复用，返回稳定 key，第一版不提供更名/分层管理。历史标签导入只增词库，不重写任务和事件；无可见任务的历史私有标签不进入普通成员搜索。明确创建的词条名称属于共享词库内容。

标签只描述任务，不触发业务流程。手动发布默认 custom，不再从首标签推导旧 kind；保留旧 kind API 兼容与自动任务来源。旧 MCP 客户端显式提交新名称仍在任务事务内注册，推荐先搜索、复用或显式新建。多标签筛选取任一匹配，与其他条件交集；服务端先筛选再分页，候选词库不取当前任务页。

新增 member_work_paused 标记以兼容既有 member_status 数据库约束；服务统一投影为“暂不接工作”，状态写入同时维护两列。没有迁移人物身份或自动改状态。

已有月度任务文案由一次性脚本显式更新，限定北京时间本月、开启、正式自动月度来源、目的与交付要求均为旧模板；修改前重读版本，沿用任务编辑事务和历史。人工文案、关闭任务、负责人、截止时间和标签均保留。
