# 猎头知识库独立存储与发布

知识库保存共同参考文章、版本和认可过程，采用独立的 Cloudflare D1、Worker、迁移目录及发布流程。人事网站继续拥有账号、正式社员身份、人物观察、人员认可额度及审核任务；知识服务仅通过主站身份接口核验当前调用者，不绑定或复制主站数据库。此边界由维护者于 2026-11-12 明确要求，不能为方便联表而重新合库。

发布后的内容版本不可原地改写，认可绑定提案及具体版本。条目当前生效版本与征求认可的修订分开保存；三份有效提交的不同账号认可在同一知识库事务内推进版本或关闭条目。资格按每次认可提交时的主站身份核验结果留证，之后身份变化不追溯撤销既有认可。跨服务身份核验与知识事务不声称具有跨库原子性；身份服务不可用时拒绝新增操作。

允许多人分别起草和提交修订；同一生效版本上的提案先达到门槛者生效，其余提案标为已被替代，须依据最新版本重新提交。关闭提案同样绑定发起时的生效版本，防止关闭讨论期间刚通过的新内容。七天为提交时刻起连续 168 小时，到期时刻起不再接受认可。管理员没有直接采纳、关闭或代他人认可的捷径。
