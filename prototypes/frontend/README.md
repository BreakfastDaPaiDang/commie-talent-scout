# 前端原型 · 第二版

本轮重新设计字号、顶部导航、档案布局与两种默认头像，并落实审阅后的状态绑定、删除可见性和自动阅读交互。使用虚构数据及内存状态，刷新复位，不连接正式账号、数据库或 MCP。

首次安装：`npm install`。启动：`npm run dev`。构建：`npm run build`。

- [桌面](http://127.0.0.1:5181/)
- [手机预览](http://127.0.0.1:5181/?preview=mobile)
- [登录](http://127.0.0.1:5181/?page=login)：任意非空演示账号与密码

顶部当前账号可切换预览身份。共有十六名虚构成员，一名冻结；管理员周宁可查看全部删除记录，普通成员沈舟不可查看何其/周宁删除内容，何其可查看自己的删除内容及历史图片。

工作状态必须选择负责成员，其他状态可选关联；下拉支持姓名/账号搜索及多人选择。详情只显示当前状态绑定，旧关联留在历史。没有别名、简介或手工已读按钮。支持图文记录编辑、删除/恢复、历史与关闭只读交互。

人物填有效 QQ 后，通过本机 Vite 帮助路由获取头像；组织只能上传头像。无图或失败使用各自设计的默认角色。QQ 路由固定上游、限时限量并缓存，只有开发服务可用，生产应用必须另做鉴权、私有存储和关闭/冻结策略。

默认字体为本地 Noto Sans SC，可变字重，[附 OFL](./public/fonts/OFL.txt)。设计取舍、探索图和验收边界见 [设计说明](../../docs/design/README.md)。

虚构组织“北岸公共空间”和何其的删除记录有 SVG 附件供展示检查；正式上传格式仅 PNG/JPEG/WebP。浏览器扩展文件上传权限未开启，选图流程未完成自动化验收。账号管理不创建真实密码，Agent 页不创建真实凭证；此原型不是生产应用。
