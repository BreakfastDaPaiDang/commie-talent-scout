# 前端原型

问题：固定在简洁、现代构成主义风格后，怎样组织档案列表、详情、图文记录和辅助页面，才能兼顾快速浏览、长文阅读与窄屏操作？

该原型整合生图灵感，不再做三个不同风格的切换版本。使用虚构数据和内存状态，刷新即可复位，没有接入正式账号、数据库、MCP 或 QQ 头像服务。界面上的权限演示不替代服务端校验；这不是生产应用。

首次安装：`npm install`。启动：`npm run dev`，打开 http://127.0.0.1:5181 。构建检查：`npm run build`。

默认进入人物页，可通过左下角入口查看登录页，使用任意非空演示账号和密码进入。可浏览人物/组织、筛选档案、编辑资料、自由切换合法状态、关闭与重新开启、发布/编辑/删除/恢复自己的记录、查看历史和未读更新。账号页提供虚构账号管理演示；Agent 页只展示布局和接入说明占位，不生成真实凭证。

设计取舍与灵感来源见 ../../docs/design/README.md 。确认后的布局与交互写回设计说明，再在正式业务层上实现；不直接把内存演示代码提升为生产代码。

窄屏预览：http://127.0.0.1:5181/?preview=mobile ，登录页：http://127.0.0.1:5181/?page=login 。组织「北岸公共空间」有一张虚构 SVG 附件供大图和历史查看；生产方案只接受 PNG/JPEG/WebP，原型 SVG 不是上传格式承诺。

已通过构建与浏览器交互自查。未读按档案汇总、记录编辑只改文字、账号不生成密码，这些为原型边界；细节和文件选择器未完成验证的原因见[设计自查](../../docs/design/README.md)。
