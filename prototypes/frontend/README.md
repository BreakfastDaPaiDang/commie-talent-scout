# 前端原型 · 第四版

2026-09-09：界面组件、图标和基础样式已迁到仓库 `app/ui/`，本原型与正式站共用，继续在原型中使用虚构内存数据。请在仓库根目录和此目录分别安装依赖；预览采用同一份布局，避免两份界面继续分叉。约定见 [frontend.md](../../docs/agents/frontend.md)。

2026-09-08 补充电脑端 UI 打磨：保留第四版视觉方向和正文 21px 字号，缩短详情阅读行宽、收紧列表间距、提高观察输入框及常用操作的可见度；弹窗固定保存区，错误在弹窗内显示，支持自动聚焦、关闭后返回触发按钮和动态标签键盘切换。详见 [本轮验收](../../docs/design/README.md#电脑端-ui-打磨2026-09-08)。

本轮新增星形 Logo 与登录插画，压缩登录冗余文案，调整列表信息位置、上传头像优先级和整体字号。延续 Assembly 结构及跨档案连续工作交互。使用虚构数据及内存状态，刷新复位，不连接正式账号、数据库或 MCP。

首次安装：`npm install`。启动：`npm run dev`。构建：`npm run build`。

- [手机预览](http://127.0.0.1:5181/?preview=mobile)
- [Agent 接入](http://127.0.0.1:5181/?page=agent)：短使用说明和一个复制按钮
- [登录](http://127.0.0.1:5181/?page=login)：任意非空演示账号与密码

顶部当前账号可切换预览身份。共有十六名虚构成员，一名冻结；管理员周宁可查看全部删除记录，普通成员沈舟不可查看何其/周宁删除内容，何其可查看自己的删除内容及历史图片。

“我负责”只显示当前工作状态绑定本人的档案；搜索覆盖名称、联系方式和未删除观察正文，命中旧记录可直接定位。搜索/筛选按成员及页面记忆；未发布观察和详情滚动位置按成员及档案保留，切页后可继续，刷新清空。未读页逐条阅读时保留已阅位置，下一处未读可跨人物与组织。

预览尺寸可切换 375、390、768、1024、1440 像素。第三版新增透明 PNG 插画和可编辑 SVG，已用于 Agent 页、全部读完状态、观察输入框和工作标记，见 [资产说明](../../docs/design/v3/README.md)。

工作状态必须选择负责成员，其他状态可选关联；下拉支持姓名/账号搜索及多人选择。详情只显示当前状态绑定，旧关联留在历史。没有别名、简介或手工已读按钮。支持图文记录编辑、删除/恢复、历史与关闭只读交互。

人物和猎头账号支持上传、更换、移除头像，优先使用上传图，其次通过本机 Vite 帮助路由取 QQ 图，再回退默认角色；组织使用上传图或默认组织形象。猎头账号入口可维护本人的头像与备用 QQ。QQ 路由固定上游、限时限量并缓存，只有开发服务可用，生产应用必须另做鉴权、私有存储和关闭/冻结策略。

列表状态与负责人/关联位于摘要上方，底部固定显示观察条数与更新时间。正文桌面 21px、手机 19px，摘要 19/18px。新增资产与生成提示词见 [第四版品牌资产](../../docs/design/v4/README.md)。

默认字体为本地 Noto Sans SC，可变字重，[附 OFL](./public/fonts/OFL.txt)。设计取舍、探索图和验收边界见 [设计说明](../../docs/design/README.md)。

虚构组织“北岸公共空间”和何其的删除记录有 SVG 附件供展示检查；正式上传格式仅 PNG/JPEG/WebP。用户本轮已手工确认头像上传可用，自动代选文件仍受扩展限制。猎头管理不创建真实密码，Agent 页不创建真实凭证；此原型不是生产应用。
